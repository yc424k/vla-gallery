비고

핵심 특징
모션 추적을 데이터·모델·연산 규모로 키운 범용 토큰 전신 제어기다. 트랜스포머 대신 MLP를 1.2M에서 42M로 키워 test-content 성공률이 98.0%에서 99.6%로 올랐다.
비고
데이터 시간은 v1 사내 데이터셋 700시간(최신판 리타게팅 후 611시간). GPU-시간 판본별 충돌: v1 초록 9k vs v1 §2.1 32,000('128 GPUs over 3 days'), 최신판 16·32·128 GPU를 모두 50k 반복까지 학습해 약 2k·9k·21k. VLA 데이터 3,900 궤적(물체 13개 × 300)·다물체 1,000 궤적†; v1 계열 PDF는 텔레옵 시연 300개로 GR00T N1.5를 미세조정. 2025년 공개 시 가중치 없음, 체크포인트 2026-02-19·학습 코드 2026-04-10(가중치 NVIDIA Open Model License, 코드 Apache 2.0). 2026 학습 가이드는 64+ GPU 권장(2025 논문 값 아님). v4 2026-08-13(Science Robotics 11(117) eaed4592). 운동학 플래너는 'Transformers or Conv1D'.
