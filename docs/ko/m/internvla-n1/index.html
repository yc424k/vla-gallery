VLA내비게이션8.39Bdiffusion

비고

핵심 특징
VLM 기반 System 2가 이미지 상 픽셀 목표·잠재 계획을 저주파로 내고 diffusion 기반 System 1이 이를 조건으로 고주파 궤적을 생성하는 비동기 이중 시스템 내비게이션 기반 모델이다. 시뮬레이션 전용 InternData-N1(53.5M 이미지·4,839.9 km)로 학습해 VLN-CE·VLN-PE에서 최고 수준을 내고 바퀴형·사족·휴머노이드 실로봇에 제로샷 이전했다.
비고
발표는 HF InternVLA-N1-Preview 저장소 생성(2025-07-21) 기준, 기술 보고서는 2025-09-11, DualVLN 논문 arXiv 2512.08186(2025-12); HF 변형: Preview(동기, 약 2 Hz) → wo-dagger(첫 공식판 개명) → w-NavDP*·DualVLN(권장, RGB만); 학습 GPU·시간 미공개; 데이터 규모 표기 50M 이상/53M/53.5M 혼재; 라이선스 CC BY-NC-SA 4.0; 2025-12 학습 코드 공개. 기반: NavDP: Learning Sim-to-Real Navigation Diffusion Policy with Privileged Information Guidance (arXiv 2505.08712) — 보고서가 System 1이 NavDP와 유사한 구조를 계승한다고 명시
