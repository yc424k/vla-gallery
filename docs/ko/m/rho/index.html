VLA2026 신규5.22Bflow matching

비고

핵심 특징
물리 그라운딩을 더한 Phi 계열 VLM에 542M flow matching 행동 전문가를 붙인 5B 오픈 가중치 VLA로, 사전학습 → 로봇별 midtraining → 과제 파인튜닝 → 온라인 보정의 단계적 적응 레시피를 쓴다. Rho-base를 YAM Box·UR AI Trainer·FR3 Duo용으로 midtraining한 변형은 같은 성공률에 과제 데이터를 절반만 쓰며, 실로봇 3종에서 π0.5·GR00T N1.7·MolmoAct2와 같거나 앞선다.
비고
Rho-alpha(ρα)와의 관계: 논문·프로젝트 페이지·README에는 Rho-alpha 언급이 없고, 프로젝트 리드 Andrey Kolobov의 발표 게시물(Digg 인용, 2차)이 Rho를 'Rho-alpha VLA+ 작업의 기반(underlying)이 되는 오픈 가중치 5B VLA 계열'이라 설명함; Rho-alpha 블로그는 '수개월 내 기술 설명 공개'를 예고했었음. 공개: rho-base·rho-yam-box·rho-ur-ai-trainer·rho-fr3-duo·rho-libero·rho-roboeval 가중치(HF, MIT), 코드(GitHub MIT), BusyBox·LIBERO·RoboEval 파인튜닝 데이터; Rho-Tomyum 사전학습 데이터 일부는 비공개 자체 데이터. 온라인 적응은 FlowDAgger(보정 행동을 동결 flow로 역변환해 잠재 정책을 회귀 학습) — 잠재 정책만 학습하고 백본·행동 전문가 동결. 파인튜닝 GPU가 논문 절제 적응(B200 4장) vs README LIBERO 재현(H100 4장) A/B. 언어 백본 Phi-Phy는 Phi 계열 VLM에서 증류(논문). 체크포인트 약 10.5 GB(옵티마이저 포함 20.6 GB)
