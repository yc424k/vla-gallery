비고

핵심 특징
웹·1인칭 영상으로 사전학습한 27B MoE 영상 diffusion transformer에 작은 행동 expert를 붙여 미래 영상과 행동을 1.6초 청크 단위로 함께 예측하는 world action model이다. DROID 파인튜닝판이 NVIDIA RoboLab-120에서 46.2%(1,200회 중 555회)로 world action model·오픈소스 로봇 파운데이션 모델 중 1위를 했고, 학습 데이터에 없던 RT-1에 파인튜닝해 SimplerEnv 80.0%(RT-1 원 정책 52.4%)를 냈다.
비고
최초 발표 2026-09-30(연구 블로그 'Introducing Praxis-1', 파트너 선공개), 2026-11-11 가중치·기술 보고서 공개(Apache 2.0, 상업 사용 허용). HF runwayml/: praxis-1-base·-droid·-yam·-so101 및 NVFP4판(-droid·-yam·-so101-nvfp4)·LeRobot판(-base·-droid·-yam-lerobot), 접근 동의 게이트(자동 승인), bf16 체크포인트 17샤드 약 54 GB; GitHub runwayml/praxis-1-oss(추론·정책 서버·MuJoCo 시뮬·전체/LoRA 파인튜닝 코드), LeRobot 내장 어댑터, vLLM-Omni·Reactor 호스팅·NeMo Automodel 사후학습 지원. 학습은 Muon(대부분 행렬) + AdamW(임베딩·헤드·투영·라우터), 텍스트 인코더·VAE만 동결, 영상·행동 velocity 손실 동일 가중. RTC는 선택(기본은 청크 실행), 양팔 정지 시간 32%→5%. 동결 영상 기반 성공 예측 헤드(AUROC 0.77)는 미공개 이전 버전 연구 결과. RoboLab-120에서 Praxis-1보다 높은 4개는 LLM 에이전트(AMP1 86.0%·SenseNova-RoboRSI 57.1%)와 비공개 모델(Lakeside 51.0%·BiMind v0.5 49.2%). 한계: 닮은 물체 혼동, 모호한 지시, 단일 지시 다단계 과제. arXiv 판 없음(미확인). 기반: Runway 영상 파운데이션 모델(DDT 구조, Wang et al. 2025), 행동 expert는 DeVA와 유사(보고서 명시)
