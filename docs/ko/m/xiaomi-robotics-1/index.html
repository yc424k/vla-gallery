비고

핵심 특징
10만 시간 이상의 UMI 궤적을 VLM 자동 라벨(장면 상태 전이 서술)로 사전학습한 뒤 약 1만 시간 교차 엠바디먼트 데이터로 로봇·명령문에 정렬하는 2단계 VLA다. 사전학습 데이터·모델 규모가 커질수록 미지 환경 즉시 성능이 오르며, RoboCasa365 57.4%·RoboDojo 점수 20.07로 기존 최고(46.6%·13.07)를 넘었다.
비고
사전학습 목표는 flow matching + Choice Policies 회귀 + 0.1×NTP(VL:UMI = 1:9); DiT는 VLM의 행동 토큰 KV를 보지 않게 막아 복사 지름길을 차단; 상태 전이 캡션은 Qwen3.5-27B로 자동 생성; 객실 단위 10분 이상 여행가방 꾸리기 시연; 코드·체크포인트 2026-08-03 공개(Apache-2.0, HF Xiaomi-Robotics-1-5B model_states.pt 10.2 GB, 벤치마크별 RoboCasa·RoboCasa365·VLABench 체크포인트), 2B·10B 미공개, 사전학습 UMI 데이터 미공개; arXiv v2 2026-07-22. 전작: Xiaomi-Robotics-0 (arXiv 2602.12684) — 비동기 학습 레시피와 VL 데이터를 이어받음(논문 명시)
