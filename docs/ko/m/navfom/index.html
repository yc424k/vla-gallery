NavFoM

Peking University·Galbot·USTC·BAAI·University of Adelaide·Zhejiang University·Differential Robotics · 2025-09

VLA내비게이션7B회귀

사족·드론·바퀴형·차량 등 여러 엠바디먼트와 VLN·물체 탐색·추적·자율주행 과제를 하나의 모델로 학습한 내비게이션 기반 모델로, 시점·시간 지시 토큰과 토큰 예산 기반 이력 샘플링을 도입했다.

비고

핵심 특징
사족·드론·바퀴형·차량 등 여러 엠바디먼트와 VLN·물체 탐색·추적·자율주행 과제를 하나의 모델로 학습한 내비게이션 기반 모델로, 시점·시간 지시 토큰과 토큰 예산 기반 이력 샘플링을 도입했다. 8.02M 내비게이션 샘플로 과제별 미세조정 없이 R2R-CE(4뷰 SR 61.7%)·RxR-CE·HM3D-OVON·EVT-Bench·NAVSIM 등에서 최고 또는 경쟁 수준을 보였다.
비고
추론 GPU가 논문(RTX 4090)과 프로젝트 페이지(RTX 5090)에서 다름; 자율주행 데이터는 실제 차량 주행 로그(nuScenes·OpenScene)이며 실로봇 수집 학습 데이터는 없음; 코드·가중치 공개 링크 없음(프로젝트 페이지 기준); ICLR 2026.
