비고
수정 반영: Jetson Orin 값은 TensorRT DiT-only 모드로 다른 기기(전체 파이프라인)와 조건이 다름. 얼리 액세스 2026-03-16(보도자료), 포럼 2026-04-17, GA 날짜 2026-07-07†(2차). 라이선스: 가중치 NVIDIA Open Model License, 코드 Apache 2.0(README 개요의 'Apache 2.0 상업 이용' 문장과 내부 상충). 사전학습 에너지 41,288 kWh, 16.949 tCO2e.
