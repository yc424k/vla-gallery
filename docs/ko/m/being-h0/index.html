핵심 특징
사람 손 영상 VLA 사전학습, 물리 공간 정렬, 로봇 태스크 사후학습을 잇는 'physical instruction tuning'을 쓴다. 실로봇 평가는 휴머노이드가 아닌 Franka 팔 + Inspire 손이라 범위 경계에 있다.
비고
파라미터(B)는 최대 변형 14B. 기관은 검증에서 Peking Univ.·Renmin Univ. 추가로 수정. 샘플 수는 논문 내부 충돌(§5.1 165M+ vs 기여 목록 150M+). 데이터 시간 1100은 '1,100시간 초과' 하한값. 가중치 1B/8B/14B·8B-Align 2025-08-02 공개, 코드 MIT(README 배지).
