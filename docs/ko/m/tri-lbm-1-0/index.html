비고

핵심 특징
LLM·VLM 없이 CLIP 언어 조건을 받는 diffusion transformer 정책이다. 실로봇 1,800회·시뮬레이션 47,000회 이상 rollouts를 베이지안 검정과 CLD로 평가했다.
비고
시뮬레이션 평가 과제 수가 출처마다 다름: 논문 16 seen + 8 unseen, 프로젝트 페이지 16 seen + 5 unseen(실기 포함 29과제). 정책 가중치 대신 시뮬레이션 벤치마크 lbm_eval(49 tasks) 공개, 정책 가중치 공개 여부는 검증 확인불가. 프로젝트 페이지 표현 '3-5× less data'. 논문·페이지에 GPU 문장 없음.
