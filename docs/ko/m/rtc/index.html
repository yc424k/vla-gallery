비고

핵심 특징
추론 지연(실기 0~10스텝 균등 샘플)을 학습 때 흉내 내 액션 prefix 조건화를 배우므로 추론시 RTC의 추가 연산이 없다. 박스 조립·에스프레소에서 추론시 RTC와 같은 성능을 더 낮은 지연으로 냈다.
비고
π0.6 기반 파인튜닝 기법이라 유형은 기타. 50 Hz 로봇에서 최대 200 ms 지연을 지원. 시뮬레이션은 지연 {0..4}를 지수 감소 가중으로 샘플.
