비고

핵심 특징
Fuyu-8B에 다수 LoRA 전문가를 희소 MoE로 넣고 VLA를 Q-함수로 보아 성공·실패가 섞인 자동 수집 데이터로 오프라인 RL 학습한 사족 VLA다. 6개 스킬 시뮬 평균 성공률 0.60으로 QUART(0.44) 등 기준선을 앞섰고 실패 데이터 추가가 RL을 통해 성능을 높였다.
비고
전문가 수·LoRA rank·Top-K 값 미기재; '백본 동결·LoRA만 학습' 서술과 FFN→MoE 전환 서술 혼재; 희소 보상(성공 시 1)+보수적 정규화(α=0.5); 추론 속도 미기재; 코드·가중치 공개 링크 없음. 기반: GeRM: A Generalist Robotic Model with Mixture-of-experts for Quadruped Robot (arXiv 2403.13358) — GeRM의 Q-함수 학습 손실과 QUARD-Auto 데이터를 그대로 활용(같은 그룹 사족 MoE 모델)
