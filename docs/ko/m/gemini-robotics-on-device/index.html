비고

핵심 특징
데이터 네트워크 없이 로봇에서 로컬로 실행되도록 최소 연산을 목표로 설계했다. DeepMind가 파인튜닝용으로 처음 제공한 VLA로, 50~100 demos로 새 과제에 적응한다.
비고
블로그 게시 2025-06-24. 블로그에 파라미터·지연·하드웨어 수치 없음. 현재 모델 페이지의 'fewer than 200 examples'는 2026년 On-Device 2 문구라 이 모델 값이 아님. GR 1.5 보고서가 baseline으로 비교.
