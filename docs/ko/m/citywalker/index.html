비고

핵심 특징
수천 시간의 YouTube 도시 보행·주행 영상에 DPVO 시각 주행거리계로 궤적 라벨을 붙여 GPS 목표 조건 도시 내비게이션 정책을 모방학습한다. 1,000시간 이상 학습 시 제로샷만으로 미세조정 ViNT보다 높은 성능을 냈고 6시간 텔레옵 미세조정 후 Go1 실환경 성공률 77.3%(미세조정 ViNT 57.1%)를 기록했다.
비고
주행 영상 비중·영상 수 미기재. 배포 시 연산 장치 미기재(속도는 RTX 3060 노트북 측정). 사전학습 모델 GitHub releases 공개. CVPR 2025.
