비고

핵심 특징
Qwen3-VL 8B 기반 VLM 위에 모션 인식·장기 기억·물리 감각(촉각·토크)을 각각 전용 스트림으로 받는 Multi-Stream Action Transformer를 얹은 정교 매니퓰레이션 VLA다. 사전학습→엠바디먼트별 mid-training→과제별 사후학습(선택적 RECAP RL) 3단계로 학습해 48자유도 ALLEX 휴머노이드 과제 평균 86.8%(π0.5·GR00T N1.6 약 40%)를 냈고, 정적 그래프·커널 융합으로 RTX 5090에서 단계당 43.7 ms까지 줄였다.
비고
합성 데이터: FLUX.2-dev 장면 편집 + 영상 생성(I2V)·Cosmos-Transfer2.5-2B V2V + IDM 행동 라벨 + 시뮬 재생·V-JEPA2 기반 동작 일치 필터, GR-1 Tabletop +9.1%p; RL은 RECAP 방식(VLM 숫자 토큰 텍스트 critic + advantage 조건 학습, 3회 반복), Best-of-N 테스트 시 critic(IQL) 실험도 부록; 시뮬 데이터는 사전학습에 쓰지 않음(논문 명시); 코드 GitHub Apache-2.0(GR00T N1.7 코드베이스 기반), 가중치 HF RLWRLD Model License v1.0(비상업·출처표시·동일조건) — PT·PT-IMG·MT-ALLEX·MT-DROID·FT 7종·RLDX-1-VLM 공개; 2026-11-12 RLDX-1.1(6.6B, 학습 2.27배·추론 최대 3.7배 빠름) 공개; RLDX-1.1 README의 RLDX-1 재평가치(RoboCasa 70.8·GR-1 58.9·RoboCasa365 36.0)는 논문값(70.6·58.7·32.1)과 다름 A/B; 프로젝트 페이지 rlwrld.ai/rldx-1 접속 실패(미확인). 기반: GR00T N1.7(학습 코드베이스, README 명시)
