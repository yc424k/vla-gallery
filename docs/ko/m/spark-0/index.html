비고

핵심 특징
촉각 장갑에서 얻은 접촉 맵과 동결 Depth-Anything-3 특징으로 시각 토큰을 학습 때만 감독하고, 별도 촉각 경로가 영역별 힘 이력과 3D taxel 상태로 행동 전문가만 조건화하는 VTLA 모델이다. 체크포인트 하나로 시각 전용·촉각 조건 배치를 모두 지원하며, 1,000시간 HumanTouch 촉각 사전학습으로 Ego Humanoid 시각 전용 성공률을 52.5%에서 71.7%로, SparkArena-Real 성공률을 44.0%에서 52.0%로 올렸다.
비고
샘플링 가중치 HumanTouch 0.35·EgoDex 0.39·같은 장갑 로봇 0.09; 사람 데이터는 IK로 WUJI 손에 리타기팅; 상태·행동 58차원(논문) vs 54차원(README) A/B, RTC 재계획 간격 24스텝(논문) vs 16스텝(README) A/B; 코드(GitHub MIT)·사전학습 체크포인트 pretrain_spark_0(HF, 400k 스텝 .pt 약 10.9GB)·SparkArena 공개, 파인튜닝 체크포인트·HumanTouch 데이터 공개 여부 미기재; XPolicyLab에도 통합. 기반: StarVLA (논문 [3]) — StarVLA·XPolicyLab 코드 위에 구축(논문 명시)
