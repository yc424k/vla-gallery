Light Origins · 2026-08

비고

핵심 특징
사전학습 VLM에 새 헤드 없이 포인팅 토큰과 RVQ 행동 토큰만 더해 지시 추종·물체 탐색·시각 추적을 한 토큰 인터페이스로 통합하고 ER 중간학습→SFT→GRPO RL 순으로 학습한다. 단안 RGB만으로 10개 공개 시뮬 설정에서 단안 기준 최고 성공률(R2R-CE SR 68.5%, EVT-Bench STT SR 91.7%)을 냈고 휴머노이드·사족·비행·바퀴형 로봇에 제로샷 이전했다.
비고
GPU-시간은 두 명시값 합산(RL 단계 시간 미공개). 데이터 시간(h)은 '4K+ hours' 하한. 가중치 HF LightOriginsHQ/LightNav-0, 코드 Apache 2.0, INSIGHT-Bench 별도 공개. 블로그(2026-09-01)는 2,000+ 인터넷 실세계 장면을 재사용 시뮬 세계로 변환했다고 설명. TRON 1·LightBot-0의 유형별 분류는 원문 미기재.
