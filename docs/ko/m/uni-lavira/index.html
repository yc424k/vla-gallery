Uni-LaViRA

Nanjing University·Institute of Automation, Chinese Academy of Sciences·Beihang University·BMW (Nanjing) Information Technology Co., Ltd.·University of Rochester · 2026-05

기타내비게이션미공개기타

사전학습 MLLM이 언어로 방향을 고르고 시각으로 목표 픽셀을 짚으면 이를 로봇 행동으로 번역하는 학습 없는 에이전트로, TODO List Memory와 Second Chance Backtrack을 더해 4개 과제군·4종 로봇을 한 구조로 다룬다.

비고

핵심 특징
사전학습 MLLM이 언어로 방향을 고르고 시각으로 목표 픽셀을 짚으면 이를 로봇 행동으로 번역하는 학습 없는 에이전트로, TODO List Memory와 Second Chance Backtrack을 더해 4개 과제군·4종 로봇을 한 구조로 다룬다. 로봇 데이터 학습 없이 R2R-CE SR 60.7%·HM3D-v2 ObjectNav SR 77.7%를 내 학습 기반 내비게이션 파운데이션 모델과 대등하거나 앞섰다.
비고
자체 학습 가중치 없음(학습 없는 프레임워크): 시뮬 주 결과는 비공개 Gemini-3.1-Pro API에 의존하고 VA Qwen3.5-27B·실로봇 Qwen3.5 Q4·하위 NavDP는 공개 가중치라 '일부'로 표기. 코드 공개(CC BY-NC-SA 4.0). 실로봇 지상 3종은 FMM 대신 NavDP를 Robot Action 단계로 사용. 기관 Beihang University는 프로젝트 페이지 저자 표기 기준. 선행작 LaViRA(제로샷 VLN-CE) 확장. 기반: LaViRA: Language-Vision-Robot Actions Translation for Zero-Shot Vision Language Navigation in Continuous Environments (arXiv 2510.19655) — 공식 코드 README가 'This work builds on LaViRA'로 명시, 프로젝트 페이지 'Previously on LaViRA'
