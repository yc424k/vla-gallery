비고

핵심 특징
단안 RGB 영상 이력과 언어 지시만으로 다음 행동을 언어로 출력하는 영상 VLM 기반 VLN 에이전트로, 지도·오도메트리·깊이 없이 연속 환경(VLN-CE)에서 동작한다. 시뮬 510k 샘플과 웹 데이터 763k로 공동학습해 R2R-CE SR 37.4%와 실내 200개 지시 실로봇 시험에서 sim-to-real 일반화를 보였다.
비고
README 공개 체크포인트(HF Jzzhang/NaVid, CC BY-NC 4.0)는 R2R·RxR 학습 분할로 Uni-NaVid 학습 전략에 따라 재학습한 버전으로 R2R val SR 41.9%·RxR val SR 45.7%(README 표)이며 논문 수치와 다름; 평가 코드 공개; 사전학습 칸은 LLaMA-VID 초기화 후 NaVid 학습 단계(LLaMA·텍스트 인코더만 학습) 기준; 배치·학습률 미공개; RSS 2024. 기반: LLaMA-VID: An Image is Worth 2 Tokens in Large Language Models (arXiv 2311.17043) — 논문이 영상 VLM LLaMA-VID 위에 구축했다고 명시
