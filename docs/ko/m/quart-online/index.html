Westlake University(MiLAB)·Zhejiang University·Beijing University of Posts and Telecommunications · 2024-12

VLA모바일 매니퓰레이션8B이산 토큰

연속 행동 청크를 잔차 VQ 코드로 압축하는 ACD로 MLLM이 한 번 추론에 여러 스텝 명령을 내도록 미세조정해 파라미터 축소 없이 지연을 없앤 사족 VLA다.

베이스 제어
사족보행 (명령·잠재 → RL 보행 제어기) · VLA가 10스텝 고수준 명령 청크(RVQ 토큰) 출력 → Walk These Ways 제어기가 하위 제어 주기(50 Hz)로 관절 제어

비고

핵심 특징
연속 행동 청크를 잔차 VQ 코드로 압축하는 ACD로 MLLM이 한 번 추론에 여러 스텝 명령을 내도록 미세조정해 파라미터 축소 없이 지연을 없앤 사족 VLA다. 2 Hz였던 QUART를 하위 제어 주기 50 Hz에 맞추면서 과제 성공률을 65% 높였다.
비고
파라미터 축소(5.3B·2.7B) 시 성공률 급락(0.74→0.22·0.11)을 보이고 대안으로 ACD 제안; 실로봇 상세 없음; 배치(256 vs 128)·파라미터(8B vs 9B) 출처별 상이; 코드(MIT)·가중치·QUARD 데이터 HF 공개; ICRA 2025(프로젝트 페이지). 기반: QUAR-VLA: Vision-Language-Action Model for Quadruped Robots (arXiv 2312.14457) — 2 Hz QUART를 저지연화한 후속 모델(논문 명시), QUARD 데이터 사용
