핵심 특징
사전학습 VLM을 로봇 데이터와 웹 VQA·캡션 데이터로 공동 파인튜닝해 행동을 텍스트 토큰으로 낸다. 256구간 행동 토큰 방식은 이후 자기회귀 VLA 다수가 재사용했다.
비고
파라미터(B)는 최대 변형 55B. 학습 연산은 스텝×배치로만 공개. PaLI-X-5B의 비전·언어 분해는 원문에 없음.
