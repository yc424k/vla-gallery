비고

핵심 특징
비디오 world model(GE-Base)의 표현을 경량 행동 디코더(GE-Act)가 받아 행동을 만들고, GE-Sim이 행동 조건 비디오 시뮬레이터 역할을 한다. 산업계 모델 중 단계별 GPU 수와 일수를 가장 상세히 공개했다.
비고
파라미터(B)는 총량 미공개라 null. 사전학습 GPU·TPU-시간은 GE-Base·GE-Act 사전학습 3단계 합(약 7일·3일·3일을 168·72·72 h로 환산). 언어 지시 조건 모델(GE-Base instruction-conditioned, T5-XXL)로 확인돼 VLA로 분류(노트의 VA/VLA 경계를 수정; 비디오 world model 기반이라 기타로 볼 수도 있음). 가중치 공개(노트의 미확인을 수정): GE_base 2025-08-14, GE-Sim(Cosmos2) 2025-10-22, GE-Act(Calvin) 2025-12-18. 기술보고서 공개 2025-08-08. GE-Act 'torque' 표현은 원문 확인이 엇갈려 쓰지 않음.
