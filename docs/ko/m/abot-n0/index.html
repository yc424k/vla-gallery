ABot-N0

AMAP CV Lab (Alibaba) · 2026-02

VLA내비게이션4Bflow matching

LLM Brain과 flow matching Action Expert를 묶은 Brain-Action 구조로 점·물체·지시·POI·사람 추종 5개 내비게이션 과제를 한 VLA로 통합하고, 16.9M 전문가 궤적·5.0M 추론 샘플 데이터 엔진과 SAFE-GRPO RL로 학습한다.

베이스 제어

비고

핵심 특징
LLM Brain과 flow matching Action Expert를 묶은 Brain-Action 구조로 점·물체·지시·POI·사람 추종 5개 내비게이션 과제를 한 VLA로 통합하고, 16.9M 전문가 궤적·5.0M 추론 샘플 데이터 엔진과 SAFE-GRPO RL로 학습한다. 7개 벤치마크(R2R-CE SR 66.4%, SocNav 폐루프 SR 88.3% 등)에서 SOTA를 주장하며 Go2의 Jetson Orin NX에서 2 Hz로 온보드 구동된다.
비고
README·논문에 가중치·코드 공개 언급 없음(README는 논문·프로젝트 페이지만, Apache 2.0 표기). 장면 면적 상충: 논문 10.7 km² vs README 10.3 km². 문서 일부에 'ABot-NO' 표기. 하위 Neural Controller는 CE-Nav 기반 VelFlow 전문가를 Isaac Sim RL로 미세조정. 학습 연산·총 파라미터 미공개.
