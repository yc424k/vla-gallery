비고

핵심 특징
앞발 하나로 매개변수화된 베지어 궤적을 추종하며 나머지 세 다리로 보행하는 RL 저수준 제어기와, 점군 기반 DP3 diffusion 플래너가 궤적 파라미터를 내는 계층형 다리 조작 정책이다. 팔 없이 다리만으로 버튼 누르기·문 밀기·이동 중 바구니 들기 등을 시뮬과 실로봇(Aliengo)에서 수행했다.
비고
시연은 사람 텔레옵이 아니라 설계한 전문가 궤적 파라미터를 RL 제어기가 시뮬에서 추적해 생성; 플래너는 베이스 속도를 직접 내지 않고 월드 좌표 목표(4 m×4 m 범위로 학습)로 이동 유도; 실로봇 정량 결과 없음; 코드·가중치 미공개. 기반: 3D Diffusion Policy: Generalizable Visuomotor Policy Learning via Simple 3D Representations (arXiv 2403.03954) — 고수준 플래너 백본으로 DP3 사용(논문 명시)
