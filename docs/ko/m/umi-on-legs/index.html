UMI on Legs

Stanford University·Columbia University·Google DeepMind · 2024-07

VA모바일 매니퓰레이션미공개diffusion

비고

핵심 특징
UMI 핸드헬드 시연으로 학습한 diffusion 조작 정책이 태스크 좌표 말단 궤적을 내면, 시뮬 RL로 학습한 조작 중심 전신 제어기(WBC)가 이를 추종해 사족+팔로 실행한다. 고정 팔용 UMI 공개 정책을 수정 없이 사족에 이식했고 던지기·밀기·컵 재배치 모두 실로봇 70% 이상 성공했다.
비고
WBC의 GPU·병렬 환경 수·학습 시간은 논문 미기재(README: legged_gym PPO·IsaacGym 기반); CLIP 인코더 변형 미기재(UMI 원 논문 컵 정책은 ViT-B/16); 코드·WBC 체크포인트·궤적 데이터 공개, 던지기·밀기 DP 체크포인트 공개는 미확인; CoRL 2024. 기반: Universal Manipulation Interface: In-The-Wild Robot Teaching Without In-The-Wild Robots (arXiv 2402.10329) — UMI 시연 데이터·정책·코드를 사족 플랫폼으로 확장(논문·README 명시)
