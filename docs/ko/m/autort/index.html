핵심 특징
로봇 함대를 LLM·VLM으로 조율해 실환경 데이터를 대규모로 수집하는 시스템이며 모델이 아니다. 수정한 Asimov 원칙 기반 'robot constitution'으로 과제를 안전성 기준으로 걸러낸다.
비고
데이터 수집 시스템(모델 아님)이라 유형 기타. 감독 비율: 모바일 1인당 3~5대, 고정형 1인당 최대 8대. 블로그는 'instructions' 대신 'tasks'로 표기.
