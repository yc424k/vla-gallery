핵심 특징
실세계 조작 데이터 270,000 h로 사전학습한 embodied foundation model이다. 7B에서 상전이가 나타나 작은 모델은 'ossification'을 보이며, 사전학습 데이터 규모와 다운스트림 성능 사이에 power-law를 보고했다.
비고
파라미터(B)는 '10B+' 표기의 하한값 10. 사후학습에 언어 조건 데이터를 쓰지만 회사가 VLA로 명명하지 않아 유형 기타. 데이터 규모는 회사 블로그 단독 주장(외부 검증 없음). 발표 2025-11-04.
