VLM이 생성한 추론 문장을 FiLM으로 확산 정책 헤드에 주입하며, GPT-4o로 학습 데이터를 추론 포함 형식으로 바꿨다. 미지 물체 102개 제로샷 bin picking에서 63.7%를 냈다.
