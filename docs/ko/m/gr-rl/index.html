비고

핵심 특징
학습한 task progress(Q값)로 시연을 거르고, 좌우 대칭 증강 후 잠재 노이즈 예측기로 온라인 RL을 한다. 신발끈 끼우기 성공률을 GR-3의 45.7%에서 83.3%로 높였다.
비고
GR-3는 4B, GR-RL은 critic 포함 총 5B로 기술. Seed 페이지 날짜 2025-12-02, arXiv v1 2025-12-01. 공개 저장소를 찾지 못함(검증 확인불가).
