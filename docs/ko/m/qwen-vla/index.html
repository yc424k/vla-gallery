Qwen-VLA

Qwen Team · 2026-05

VLA2026 신규미공개flow matching

Qwen VLM에 DiT flow-matching 디코더를 붙여 조작·내비게이션·궤적 예측을 하나의 행동·궤적 공간으로 묶고, 로봇별 프롬프트 조건화로 한 가중치가 여러 엠바디먼트를 다룬다.

비고

핵심 특징
Qwen VLM에 DiT flow-matching 디코더를 붙여 조작·내비게이션·궤적 예측을 하나의 행동·궤적 공간으로 묶고, 로봇별 프롬프트 조건화로 한 가중치가 여러 엠바디먼트를 다룬다. 단일 범용 모델로 LIBERO 97.9%·R2R-CE SR 57.5%·RxR-CE SR 59.6%를 냈고 실 ALOHA에서 평균 83.6%(π0.5 71.6%)를 기록했다.
비고
실제 모바일 베이스 제어 실험 없음: 내비게이션은 VLN-CE R2R/RxR 시뮬 평가만, 실로봇은 고정 ALOHA라 지시대로 '2026 신규'·베이스 '고정'으로 기재. 논문 바이라인 'Owen Team'(README는 'Qwen Team'). GitHub은 정보·이슈 창구로 체크포인트 링크 없음(2026-10 기준). 총 파라미터·학습 연산·추론 지연 미공개. 데이터 시간은 출처별 수치만 있어 합계 칸은 비움.
