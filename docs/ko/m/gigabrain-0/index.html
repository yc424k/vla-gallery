world model GigaWorld로 만든 생성 데이터(Real2Real, Sim2Real, 사람 영상 변환 등)로 실로봇 데이터 의존을 줄인다. 경량판 GigaBrain-0-Small(402M)은 Jetson AGX Orin에서 0.13초로 동작한다.
비고
파라미터(B)는 본 모델 총량 미공개라 null(GigaBrain-0-Small 402M만 공개). 그림 막대 라벨의 과제별 절대 성공률은 검증 확인불가라 본문의 차이(+30%, +10%)만 사용. 가중치 2025-11-27 공개(저장소 Apache-2.0). README의 GigaBrain-0.7은 2026 릴리스라 제외. 데이터 시간(h)은 자체 데이터만. arXiv v1 2025-10-22.
