비고

핵심 특징
UI 내비게이션과 로봇 조작을 함께 다루는 멀티모달 에이전트 기반 모델이다. Set-of-Mark로 행동을 그라운딩하고 Trace-of-Mark로 영상에서 계획을 배운다.
비고
학습 하드웨어는 모델 카드에만 있고 논문에는 없다. 가중치 공개 2025-02-25. UI 에이전트 작업도 포함한다. 파라미터(B)는 논문 값 8.6B다.
