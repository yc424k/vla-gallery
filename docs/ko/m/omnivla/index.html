OmniVLA

UC Berkeley·Toyota Motor North America·Princeton University · 2025-09

VLA내비게이션7.5B회귀

언어·목표 이미지·2D 목표 위치를 단독 또는 조합으로 받는 옴니모달 내비게이션 VLA로, OpenVLA 7B를 10개 플랫폼 9,500시간 데이터로 LoRA 학습했다.

구조 원문 요약
OpenVLA 7B(Llama 2-7B + DINOv2·SigLIP, 총 7.5B)에 현재·목표 이미지, 2D 목표 위치, 언어 입력(modality dropout으로 목표 조합 마스킹) → LLM 출력의 선형 행동 헤드(OpenVLA-OFT식)로 웨이포인트 8개(3 Hz, 2.4초) 회귀 → 선속도·각속도 명령; 경량판 OmniVLA-edge 50M(ViNT 기반, EfficientNet-B0·CLIP·FiLM)

비고

핵심 특징
언어·목표 이미지·2D 목표 위치를 단독 또는 조합으로 받는 옴니모달 내비게이션 VLA로, OpenVLA 7B를 10개 플랫폼 9,500시간 데이터로 LoRA 학습했다. 실로봇에서 언어 목표 성공률 0.73(LeLaN 0.43)·2D 위치 0.95·목표 이미지 1.00으로 모달리티별 전용 정책과 같거나 높았다.
비고
LoRA로 학습 파라미터 약 5%로 제한. FrodoBots·BDD-V는 MBRA, LeLaN은 NoMaD 합성 행동 라벨. HF 페이지 자동 표기 '8B params'(논문 7.5B), BF16 safetensors 약 15.1GB. 학습 시간·추론 지연 미공개. ICRA 2026. 기반: OpenVLA: An Open-Source Vision-Language-Action Model (arXiv 2406.09246) — OpenVLA 7B 체크포인트에서 학습 시작, OpenVLA-OFT 코드베이스 기반 (README)
