핵심 특징
220만 시간 이상의 사람 경험(웹·1인칭 영상, LiberSense Glove 손 동작, 교차 엠바디먼트 로봇 데이터)으로 시각 예측 → 영상·행동 공동 예측 → 매니퓰레이션 집중의 3단계 사전학습을 거친 world action model이다. 목표 과제용 로봇 시연 없이 GPT-6가 제안한 60과제(600회)에서 성공률 36.0%(PnP 63.5%·짧은 Non-PnP 34.0%·다단계 10.5%)를 냈고, 장갑 데이터 10,000시간이 200배 많은 웹 사람 영상보다 잘 전이된다고 보고했다.
비고
LiberSense Glove는 두께 0.3 mm·무게 131 g, 1인칭·양 손목 카메라와 손 자세 동기화(접촉·힘은 미측정); 시연자 1→100명(에피소드 수 고정)으로 장갑 전용 진행 점수 12.7→40.1; 'zero-shot'은 목표 과제용 로봇 시연이 없다는 뜻이며 사전학습에는 로봇 데이터 포함; 성능은 모두 자체 보고. 공식 기술 블로그 2026-11-04(보도자료 2026-11-03, ACCESS Newswire), 보도자료의 'GPT-6 Astra 5%'는 블로그상 짧은 Non-PnP 5.0%이고 전체 수치는 블로그에 없음(2차). 가중치: 블로그 모델 자체는 미공개, HF에 RoboDojo 평가 체크포인트 Liber0-Preview-Robodojo(2026-10-14)·Liber0-Lite-Robodojo(2026-10-10, pretrain/ 초기화 가중치 포함) 공개(라이선스 미기재, 두 model.pt sha256 동일); Lite 추론 코드는 개인 계정 XPolicyLab 포크(zhangxiwen1810/XPolicyLab, liber-0 브랜치) 링크(공식 여부 미확인). 기반: World Action Models are Zero-shot Policies (arXiv 2602.15922)·Mixture-of-Transformers (블로그 인용)
