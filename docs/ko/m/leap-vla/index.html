Leap-VLA

Leapmotor (Embodied Algorithm Group, Automation PBU) · 2026-10

VLA2026 신규미공개flow matching

VLM은 0.5~2초마다 갱신하는 의미 캐시로만 돌리고, 행동 전문가는 측정된 캐시 나이와 새 저지연 영상 토큰으로 50 ms 주기 제어를 맡도록 한 VLA다.

비고

핵심 특징
VLM은 0.5~2초마다 갱신하는 의미 캐시로만 돌리고, 행동 전문가는 측정된 캐시 나이와 새 저지연 영상 토큰으로 50 ms 주기 제어를 맡도록 한 VLA다. 실제 에피소드 이력에서 뽑은 캐시 나이와 나이에 비례한 픽셀 가림으로 학습해 LIBERO-Spatial 2초 갱신 성공률을 61.4%에서 95.5%로 회복했고, 전방 계산만 쓰는 청크 경계 보정(soft-nudge)으로 매 제어 스텝 재계획에서 97.1%를 냈다.
비고
고속 인코더는 마스크 복원(약 49% 띠 마스크) + WAFT 광류 + Depth Anything V2 깊이 교사로 사전학습 후 동결, 프레임 간격 δ=0.2 s; 캐시 나이는 log(1+τ) 사인 임베딩을 0 초기화 투영으로 주입, Δmax=2 s; 캐시 갱신은 주기·이벤트(프레임 차·그리퍼·하위 과제)·에피소드 리셋(보고 실험은 주기·리셋만); soft-nudge는 RTC guidance의 Jacobian 전치를 항등으로 바꾼 전방 전용 보정으로 TensorRT/NPU 내보내기 그래프를 바꾸지 않음; CoT verdict 게이트가 명령-장면 불일치 166/180 에피소드를 막고 가능 과제 20/20 유지; 실로봇은 의미 갱신 1:4; 비동기 평가 프로토콜 공개 언급만 있고 코드·가중치 링크 없음; 이름이 같은 MERL의 LEAP-VLA(InternVL3-1B, GitHub AndersonYu7/LEAP-VLA)와는 별개 모델. 기반: π0 (arXiv 2410.24164) — VLM prefix와 flow matching 행동 전문가의 공유 어텐션 결합을 따름(논문 명시)
