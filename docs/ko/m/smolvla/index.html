핵심 특징
커뮤니티 SO100 데이터셋 481개로 사전학습한 0.45B 소형 VLA로, 단일 GPU 학습과 소비자 GPU·CPU 배포를 목표로 한다. 비동기 추론으로 과제 완료 시간을 약 30% 줄였다.
비고
파라미터(B)는 Table 2 최대 변형 2.25B(주 모델·공개 가중치 0.45B). 사전학습에 시뮬레이션 데이터 미사용, 과제 설명은 Qwen2.5-VL-3B-Instruct로 자동 생성. 30k GPU-시간은 프로젝트 전체 값.
