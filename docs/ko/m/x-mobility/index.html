X-Mobility

NVIDIA·UT Austin·UC Berkeley · 2024-10

VA내비게이션미공개회귀

자기회귀 잠재 world model로 환경 동역학을 먼저 학습하고 그 잠재 상태 위에서 행동 정책을 분리 학습해 시뮬 데이터만으로 일반화하는 종단간 내비게이션 모델이다.

비고

핵심 특징
자기회귀 잠재 world model로 환경 동역학을 먼저 학습하고 그 잠재 상태 위에서 행동 정책을 분리 학습해 시뮬 데이터만으로 일반화하는 종단간 내비게이션 모델이다. Isaac Sim 창고에서 성공률 96%(Nav2 58%)를 보였고 미세조정 없이 실제 Nova Carter에 제로샷 배포했다.
비고
2단계 학습(무작위 행동으로 world model 사전학습 → Nav2 교사 데이터로 정책 추가). 총 파라미터·학습 시간 미공개. HF 체크포인트 1.44GB(x_mobility-nav2-semantic_action_path.ckpt), Apache 2.0 코드. 후속 COMPASS의 기반 정책.
