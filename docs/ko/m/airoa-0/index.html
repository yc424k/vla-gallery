비고

핵심 특징
로봇 데이터 없이 오픈소스 핸드헬드 그리퍼 YUBI로 모은 16,151시간 양팔 시연만으로 사전·사후학습하고, 양 손목 카메라 두 대만으로 학습 데이터가 없는 장소에서 장기·정밀 과제를 수행하는 π0.5 기반 VLA다. 시각 예산 게이트·단계 예측·고유감각 메모리·비균일 스트리밍 디코딩을 더해 Franka 10과제 평균 성공률 78%(π0.5·XR-1·GR00T N1.7·MolmoAct2 중 최고 27%)를 냈고, 같은 가중치가 TX-G2·OpenArm·UR에서도 돈다.
비고
사전학습 목표는 See Less, Specify More(S2): flow matching 행동 손실 + 시각 예산 손실 + 하위과제 텍스트 예측 보조 손실(학습 전용), 과제·하위과제 지시문 두 수준 조건; 상태는 한 그리퍼 기준 다른 그리퍼 자세 + 양 그리퍼 개폐(11차원)로 로봇 기저·관절·월드 좌표를 쓰지 않음; 사후학습 손실은 행동 + 0.1×예산 + 0.1×단계 + 0.01×하위과제; 가중치는 HF 게이트(Gemma Terms of Use) 공개 — pretrained + 사후학습 예시 3개(orange_pyramid·towel_folding·letter_blocks, 20k 스텝 EMA), 체크포인트당 약 12 GB(bf16 약 6.7 GB); 사후학습 코드 GitHub(Apache-2.0, OpenPI 기반, JAX); 16,151시간 데이터셋은 공개 발표했으나 프로젝트 페이지 'Coming soon'(2026-11-13 확인); 텔레옵·강화학습·로봇 현장 보정·시뮬 미사용 명시; NEDO 과제 JPNP25015. 기반: π0.5: a Vision-Language-Action Model with Open-World Generalization (arXiv 2504.16054) — π0.5 base 체크포인트에서 초기화해 백본을 그대로 씀(논문 명시)
