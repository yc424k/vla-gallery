핵심 특징
전방향(holonomic) 파워드 캐스터 베이스와 휴대폰 텔레옵 시연으로 과제별 Diffusion Policy를 학습해 베이스 목표 자세와 팔 말단 목표를 함께 출력한다. 실제 아파트 6과제에서 6/10~10/10을 성공했고, 같은 조건의 차동구동 제약 정책은 걸레질 과제에서 4/10(전방향 9/10)에 그쳤다.
비고
논문은 정책을 'diffusion policy'로만 기술하며 구조·주파수·지연은 공식 GitHub 코드·README 기준. 하드웨어 설계·텔레옵·학습·제어 코드 오픈소스; 가중치는 시뮬 sim-v1 정책 체크포인트만 공개(실과제 정책 미공개). 모델 크기·학습 GPU 기종·시간 미공개. 기반: Diffusion Policy: Visuomotor Policy Learning via Action Diffusion (arXiv 2303.04137) — 논문·README가 정책 학습에 Diffusion Policy(real-stanford/diffusion_policy 코드)를 그대로 사용
