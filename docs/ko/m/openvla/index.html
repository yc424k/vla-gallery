핵심 특징
OXE 970k 궤적으로 학습한 공개 7B VLA로, ECoT·TraceVLA·OpenVLA-OFT·UniVLA 등이 이 스택을 기반으로 했다. 사전학습 컴퓨트를 21,500 A100-시간으로 명시했다.
비고
학습 기간이 논문 14일, 프로젝트 페이지 15일로 다르다. Table 1의 Full FT 163.3 GB는 batch 16을 GPU 2장에 FSDP로 나눈 합계다. LIBERO 파인튜닝 부록(App E)은 확인하지 못했다. 파라미터(B)는 논문 값 7B다.
