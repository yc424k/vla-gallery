QUAR-VLA (QUART)

Westlake University·Zhejiang University · 2023-12

VLA모바일 매니퓰레이션8B이산 토큰

비고

핵심 특징
단일 RGB와 언어 지시로 사족 고수준 명령(속도·보행·자세)을 이산 토큰으로 내는 사족 VLA 과제 정의와 QUART 모델, 시뮬·실로봇 QUARD 데이터셋을 제안했다. 4,000회 평가로 대규모 시뮬 데이터와 소량 실데이터 공동학습이 실로봇 Go to 성공을 3/20에서 13/20으로 높임을 보였다.
비고
시뮬 데이터는 A*/D* 경로+PD 속도 변환 스크립트로 생성, 실데이터는 원격 조종; 하위 제어기 [23]=Walk These Ways(본 논문은 RL 명시 없음, 원 논문 PPO); 학습 GPU·시간 미기재; LLaVA-7B 변형도 비교(성능 유사); v1→v6 모델 구성·데이터 수치 변경; 가중치 미공개(QUARD는 QUART-Online 페이지에서 HF 공개).
