비고

핵심 특징
별도 사전학습 비전 인코더 없이 patch embedder로 픽셀을 백본 토큰 공간에 바로 넣고, flow matching 행동 전문가가 백본의 여러 깊이 층 KV를 직접 읽는 구조적 네이티브 VLA다. 같은 행동 전문가·데이터 조건에서 Qwen3-VL-2B·Gemma-3-4B 백본보다 LIBERO 성공률이 높고(백본 동결 90.9% vs 79.5%·84.5%), LIBERO-plus 89.7·RoboTwin 2.0 Clean2Rand 69.40으로 코드·가중치 공개 모델 중 최고를 보고했다.
비고
샘플링 비율 InternData-A1 15% 고정·나머지 행 수^0.43; 손실 그룹 가중치 EE·그리퍼 2, 팔 관절·손 관절·몸체 1; τ=0.999u, u~Beta(1,1.5), CFG 미사용; 층 지도 실험에서 동결 시 first-28 94.9%가 end-28 86.7%보다 높음; 행동만 파인튜닝하면 텍스트 출력이 무너지고 RoboTwin C2R 10.7%(공동학습 69.4%); 표 1 시간 열의 †·‡ 각주 설명 원문 미기재; 코드(GitHub VLAKit, Apache-2.0)·HF 체크포인트 stage1(113,400스텝)·stage2(75,000스텝)·stage2_backbone·stage_libero·stage_rtw 공개, stage_mid_train은 카드 목록에만 있고 파일 없음, 원본 NEOpp-2B-SFT 백본 미공개; 가공 사전학습 데이터 HF 공개(점진 업로드, 미완성). 기반: NEO (Diao et al., ICLR 2026 'From Pixels to Words') — 네이티브 비전-언어 백본을 그대로 씀(논문 명시)
