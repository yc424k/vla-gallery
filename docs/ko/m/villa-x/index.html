비고

핵심 특징
잠재 액션을 중간 계획으로 두고 로봇 액션 전문가와 함께 학습한다. 로봇 1.6M 궤적과 사람 영상 3.6M 클립으로 사전학습했다.
비고
노트의 '컴퓨트 미공개'와 '데이터 비율만'은 검증에서 수정됐다. GPU-시간은 actor 사전학습만이며, LAM을 더하면 약 18,432 A100-시간이다. 가중치는 LAM만 공개됐다.
