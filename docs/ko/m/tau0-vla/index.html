Shanghai Innovation Institute·Agibot Finch·CUHK · 2026-08

비고

핵심 특징
실행 메모리를 가진 상위 정책이 world model로 후보 하위 과제의 결과 영상을 예측하고 가치 모델로 평가해 빔 탐색하는 test-time computation 계층형 VLA이다. 40,115시간 실데이터로 학습한 하위 정책이 장기 과제 4종 평균 SR 27.5%(π0.5 22.5%)를 내고 계층 시스템(Plan Once)은 45.0%까지 올렸다.
비고
하위 정책 3단계 학습(KI 공동학습 → 종단 공동학습 → 과제별 적응); 상위 데이터 라벨링에 Gemma4-31B-it 사용; 공개 HF 가중치는 하위 사전학습 정책(제로샷 제어기 아님, 사후학습용), 상위 Proposal·World Model은 별도 공개(2026-09); HF 공개 2026-07-27, arXiv v1 2026-08-17; 코드·가중치 Apache-2.0, 예제 데이터 CC BY-NC-SA 4.0
