LeVERB (Latent Vision-Language-Encoded Robot Behavior)

UC Berkeley·NTNU·Simon Fraser University·Carnegie Mellon University · 2025-06

VLA휴머노이드 VLASystem 2 학습 파라미터 102.56M잠재 액션

잠재 행동 어휘(latent verb)로 비전-언어 계층과 전신 제어 계층을 잇는 계층형 VLA로, 시뮬에서만 학습해 G1에 zero-shot 전이한다.

핵심 특징
잠재 행동 어휘(latent verb)로 비전-언어 계층과 전신 제어 계층을 잇는 계층형 VLA로, 시뮬에서만 학습해 G1에 zero-shot 전이한다. System 1은 비전-언어 무관 RL 교사를 DAgger로 증류한다.
비고
데이터 시간은 포토리얼 롤아웃 17.1 h만(언어 전용 2.7 h 별도). 파라미터(B)는 총 파라미터 미공개로 null. System 1 교사 RL의 시뮬레이터·env·GPU 미공개(검증 NOT FOUND); 별도 행 LeVERB-A 참조. arXiv v3 2025-09-25.
