GR00T 2

NVIDIA (GEAR) · 2026-11

기타2026 신규2B 트랜스포머영상 world model

사람 1인칭 영상·UMI 시연·여러 로봇 텔레옵으로 미래 다시점 영상과 행동을 함께 예측하도록 사전학습한 2B world action model로, 시연이 없는 로봇에도 사람·UMI 시연의 기술을 옮기는 X-Adapt를 보인다.

구조 원문 요약
Cosmos-Predict2.5-2B 영상 diffusion transformer에서 초기화한 단일 2B 트랜스포머가 영상·상태·행동 토큰을 한 시퀀스로 처리: 동결 Wan 2.1 VAE(시간 4×·공간 8×, 224×320에서 잠재 프레임·카메라당 토큰 280개, 최대 4카메라·5 fps·0.8초 이력) + 동결 Cosmos-Reason1 텍스트 인코더(교차 어텐션) + 엠바디먼트별 상태·행동 MLP와 행동 디코더 → 미래 영상 잠재와 행동 청크를 flow matching으로 공동 생성(행동 토큰이 생성 중인 미래 프레임까지 어텐션), 배포 시 영상 1~2·행동 2~4 디노이징 스텝; 행동 청크 48스텝(1.6초@30 Hz, YAM·Dexter), G1 Turbo는 80스텝

비고

핵심 특징
사람 1인칭 영상·UMI 시연·여러 로봇 텔레옵으로 미래 다시점 영상과 행동을 함께 예측하도록 사전학습한 2B world action model로, 시연이 없는 로봇에도 사람·UMI 시연의 기술을 옮기는 X-Adapt를 보인다. Dexter-50 미학습 과제에서 제로샷 40%, 시연 1개 71%·5개 95%(RTX 5090 1장 LoRA 약 30분)를 기록했고, 실로봇 GRPO 사후학습으로 접촉 과제 성공률을 88~98%로 올렸다.
비고
GR00T 2 Turbo: Wan 2.2 VAE로 공간 압축 8×→16×(잠재 격자 4배 작음), 행동 청크 길이 동일, YAM V2에서 GR00T 2와 통계적으로 구분되지 않으면서 호출당 약 3배 빠름(RTX 5090 52 vs 171 ms), 정교 손 과제는 68.6%→34.3%로 하락; G1에서는 SONIC(PPO 학습 전신 제어기) 모션 토큰·그리퍼 폭을 출력. 사후학습 RL: 롤아웃 시 행동 디노이징에만 CPS 잡음, 과거 반환을 기억하는 GRPO형 목적(AutoRL 에이전트가 시뮬에서 약 35일 탐색), GRPO 성공 롤아웃 자기모방, 동결 정책 위 residual RL, DreamDojo world model 내 RL. 에이전트용 WAM API(MCP)·code-as-policy·시각 조향 지원, 데이터 주석은 Flora. 코드 '12월 공개 예정'(프로젝트 페이지), 2026-11-13 기준 GitHub NVIDIA/Isaac-GR00T는 N1.7, HF nvidia/에 GR00T 2 가중치 없음.
