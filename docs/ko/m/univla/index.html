비고

핵심 특징
과제 무관·과제 중심 2단계로 잠재 액션을 학습해 사람 영상과 내비게이션 데이터까지 사전학습에 쓴다. 사전학습은 960 A100-시간으로 OpenVLA의 약 5%다.
비고
Bridge만·사람 영상만 변형은 GPU 8장, global batch 258(원문 표기), 약 200 A100-시간이다. 잠재 액션 모델은 batch 512·100k steps이며 시간은 미공개다. 도메인에 내비게이션(R2R)도 포함한다. BAAI의 UniVLA와 다른 모델이다.
