MiniCPM-RobotManip

ModelBest(面壁智能)·OpenBMB · 2026-07

핵심 특징
MiniCPM-V 4.6 기반 1.5B 범용 VLA로, 가중치 한 벌로 LIBERO·CALVIN·RoboTwin2·RMBench를 모두 평가하며 프레임당 시각 토큰을 64개로 줄이고 이력 관측을 스트리밍으로 문맥에 누적해 최대 1분 시각 기억을 지원하는 모델이다. LIBERO 97.5·RoboTwin2 easy 91.3·hard 91.6·RMBench 53.3(π0.5 10.4)을 보고했고, H100 BF16 단일 프레임 모델 전방 지연은 결정 단계당 120 ms로 π0.5의 234 ms보다 짧다.
비고
Apache-2.0으로 추론 코드·평가 통합(LIBERO·CALVIN·RoboTwin2·RMBench)·체크포인트(HF·ModelScope) 공개, 학습 코드·학습 데이터·기술 보고서 미공개; 공개 체크포인트의 엠바디먼트 ID↔로봇 대응표 없음(RoboTwin=4만 명시); 행동 헤드 코드는 잡음과 행동을 선형 보간한 입력에서 행동을 직접 예측하는 4스텝 반복(학습 손실 미기재); 모델 카드는 1.5B, 기사 다수도 1.5B. 같은 계열: MiniCPM-RobotTrack(0.9B, MiniCPM4-0.5B 기반 목표 추적 VLA, DINOv3 ViT-S/16·SigLIP So400m 인코더 → 웨이포인트, EVT-Bench STT SR 84.1·TR 89.8, DAgger식 자기 진화 데이터, Unitree Go2 EDU + Jetson Orin NX 16GB에서 5+ FPS·약 180 ms). 기반: starVLA·LeRobot (README 감사 문구) — 평가는 starVLA 커밋 631aae02에서 이식
