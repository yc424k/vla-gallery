Helpful DoggyBot

Stanford University·UC San Diego · 2024-09

기타모바일 매니퓰레이션미공개RL 정책

베이스 제어
사족보행 (명령·잠재 → RL 보행 제어기) · VLM 검출 위치로 비례 제어기가 선속도(0.8 m/s)·요·피치 명령 생성 → 깊이 기반 RL 정책이 관절 제어

비고

핵심 특징
전면 하단 1-DoF 그리퍼를 단 Go2에 시뮬 RL로 학습한 1인칭 깊이 기반 민첩 제어기와 사전학습 VLM 인식·비례 제어를 결합한 모듈형 실내 물체 가져오기 시스템이다. 실데이터 수집·학습 없이 처음 보는 집 2곳에서 침대 위로 올라가 장난감을 가져오는 등 60–70% 성공률을 보였다.
비고
학습되는 부분은 저수준 RL 제어기뿐이고, 검출·추적은 사전학습 모델, 이동·파지 명령은 규칙 비례 제어(선속도 0.8 m/s 고정); 천장 카메라 의존을 한계로 명시; 자연어 물체 지정은 Florence-2 프롬프트; 코드 공개(GitHub), 가중치 미공개.
