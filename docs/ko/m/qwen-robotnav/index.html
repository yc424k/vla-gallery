Qwen-RobotNav

Qwen Team · 2026-06

VLA내비게이션4B·8B회귀

과제 모드와 관측 문맥(토큰 예산·시간 감쇠·카메라 가중)을 매개변수화하고 학습 때 무작위화해, 한 모델이 VLN·물체 탐색·추적·자율주행을 상위 에이전트 플래너의 도구로 수행한다.

구조 원문 요약
Qwen3-VL(4B·8B; SigLIP-2 ViT·2D-RoPE 동적 해상도·DeepStack) + 4층 MLP 행동 헤드(hidden 512) → 웨이포인트 8개(x,y,θ) 연속 회귀(MSE); 과제 모드(VLN·PointNav·ObjNav·Tracking)와 시각 토큰 예산(2048–4096)·시간 감쇠·카메라 가중·프레임 샘플링을 추론 시 조정, 상위 플래너가 도구처럼 호출; 실배치 약 5 Hz

비고

핵심 특징
과제 모드와 관측 문맥(토큰 예산·시간 감쇠·카메라 가중)을 매개변수화하고 학습 때 무작위화해, 한 모델이 VLN·물체 탐색·추적·자율주행을 상위 에이전트 플래너의 도구로 수행한다. 15.6M 샘플로 학습한 8B가 R2R-CE SR 72.1%·RxR-CE SR 76.5%(파노라마)를 냈고 Go2에서 Jetson Thor 온디바이스 4.9 Hz로 제로샷 주행했다.
비고
README: 'There is currently no plan to release the model weights'. 지연 수치 상충: 논문은 원격 196 ms·온디바이스 204 ms, README는 온디바이스 196 ms. 단안 결과(R2R SR 65.7%)는 LightNav-0 비교표와 일치. '실로봇 자율 주행 로그'는 차량 주행 데이터(nuScenes·OpenScene). 초록의 2B 변형은 결과표에 없음.
