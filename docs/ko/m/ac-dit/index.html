AC-DiT

Peking University·Nanjing University·CUHK·Beijing Academy of Artificial Intelligence(BAAI) · 2025-07

VLA모바일 매니퓰레이션미공개diffusion

베이스 행동만으로 먼저 학습한 경량 모빌리티 헤드의 잠재 표현을 전신 행동 생성의 조건으로 넣고(mobility-to-body), 단계별 필요에 따라 2D 이미지와 3D 점군의 가중치를 조절한다.

핵심 특징
베이스 행동만으로 먼저 학습한 경량 모빌리티 헤드의 잠재 표현을 전신 행동 생성의 조건으로 넣고(mobility-to-body), 단계별 필요에 따라 2D 이미지와 3D 점군의 가중치를 조절한다. ManiSkill-HAB에서 RDT·DP·3DP보다 높았고 실 Cobot Magic 4개 장기 과제에서 ACT·π0를 앞섰다.
비고
논문에 학습·추론 하드웨어와 총 파라미터 미기재; RDT-1B 초기화·스텝·배치는 공식 GitHub 스크립트 기준. ManiSkill-HAB 평균이 표(55.6)와 본문(48.7%)에서 불일치. 코드 2026-02 공개, 학습된 AC-DiT 가중치 미제공. NeurIPS 2025. 기반: RDT-1B: a Diffusion Foundation Model for Bimanual Manipulation (arXiv 2410.07864) — RDT 프레임워크(교차 어텐션 조건 주입)를 따르고 공식 코드가 RDT-1B 가중치로 초기화
