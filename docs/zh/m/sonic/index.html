备注

核心特点
是将动作跟踪按数据·模型·算力规模扩展的通用token全身控制器。不用Transformer，而将MLP从1.2M扩大到42M，test-content成功率从98.0%提升到99.6%。
备注
数据时长为v1内部数据集700小时（最新版重定向后611小时）。GPU-小时各版本冲突：v1摘要 9k vs v1 §2.1 32,000（'128 GPUs over 3 days'），最新版将16·32·128 GPU均训练至50k次迭代，约 2k·9k·21k。VLA数据 3,900条轨迹（物体13个 × 300）·多物体 1,000条轨迹†；v1系列PDF用遥操作演示300条微调GR00T N1.5。2025年公开时无权重，检查点 2026-02-19·训练代码 2026-04-10（权重 NVIDIA Open Model License，代码 Apache 2.0）。2026训练指南建议64+ GPU（非2025论文值）。v4 2026-08-13（Science Robotics 11(117) eaed4592）。运动学规划器为'Transformers or Conv1D'。
