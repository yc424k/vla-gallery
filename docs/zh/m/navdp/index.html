架构原文摘要
RGB用预训练DepthAnything ViT、深度用从头训练的ViT编码 → Transformer解码器将RGB-D 512个token压缩为16个融合token → 2层Transformer编码器(策略·critic共享) → 条件U-Net·DDPM diffusion头批量生成24步航点(Δx,Δy,Δω),critic(轨迹用1D conv编码)打分选出最佳轨迹;以轨迹中间点×比例系数计算线速度·角速度,>10 Hz

备注

核心特点
仅用仿真数据，以单个Transformer从RGB-D观测联合学习轨迹生成(diffusion)与轨迹评估(critic)，critic以仿真特权信息(全局ESDF)构造的对比负样本轨迹训练。无需真实机器人数据即可零样本迁移到四足·轮式·人形机器人，加入Gaussian Splatting real-to-sim数据(约4k条轨迹)后真实环境成功率由50%升至80%。
