备注

核心特点
在π0.5中插入全景专家的Mixture-of-Transformers，将360°全景的全局空间上下文与局部相机视图融合，并用单一VR全身遥操作采集轮式双臂机器人数据。在4项真实任务中平均阶段完成率91.3%·最终成功率73.4%，大幅超过π0.5(58.6%·30.0%)。
备注
遥操作：VR头显·双手控制器·腰/脚踝追踪器3个 → SMPL重建 → GMR重定向(底盘为3-DoF平面虚拟floating base)。π0.5检查点名称·总参数·去噪步数·训练时间未公开。论文未提及代码·数据·权重公开。基于：π0.5: a Vision-Language-Action Model with Open-World Generalization (arXiv 2504.16054) — 在π0.5双专家主干中插入全景专家构成
