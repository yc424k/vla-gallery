备注

核心特点
在基于Qwen3-VL 8B的VLM之上，加装以专用流分别接收运动感知·长期记忆·物理感觉(触觉·力矩)的Multi-Stream Action Transformer的灵巧操作VLA。按预训练→按本体mid-training→按任务后训练(可选RECAP RL) 3阶段训练，在48自由度ALLEX人形机器人任务上平均达86.8%(π0.5·GR00T N1.6约40%)，并通过静态图·内核融合在RTX 5090上将每步缩短至43.7 ms。
备注
合成数据：FLUX.2-dev场景编辑 + 视频生成(I2V)·Cosmos-Transfer2.5-2B V2V + IDM动作标签 + 仿真回放·基于V-JEPA2的动作一致性过滤，GR-1 Tabletop +9.1%p；RL为RECAP式(VLM数字token文本critic + advantage条件训练，迭代3次)，附录另有Best-of-N测试时critic(IQL)实验；仿真数据不用于预训练(论文明示)；代码GitHub Apache-2.0(基于GR00T N1.7代码库)，权重HF RLWRLD Model License v1.0(非商用·署名·相同方式共享) — 公开PT·PT-IMG·MT-ALLEX·MT-DROID·FT 7种·RLDX-1-VLM；2026-11-12公开RLDX-1.1(6.6B，训练快2.27倍·推理最多快3.7倍)；RLDX-1.1 README中RLDX-1重新评估值(RoboCasa 70.8·GR-1 58.9·RoboCasa365 36.0)与论文值(70.6·58.7·32.1)不同 A/B；项目页rlwrld.ai/rldx-1访问失败(未核实)。基础: GR00T N1.7(训练代码库，README明示)
