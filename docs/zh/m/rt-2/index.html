PaLI-X(ViT-22B + 32B·50层编码器-解码器)或PaLM-E(ViT-4B + 12B解码器);将8个整数动作(6-DoF位移·夹爪·终止)以256区间文本token输出,无动作块

微调
加速器·时间未公开；联合微调55B：lr 1e-3·批量2048·80K步，5B：批量2048·270K步，12B：lr 4e-4·批量512·1M步，3B(Language-Table)：批量128·300K步
数据类型
真实机器人遥操作；网络视觉-语言
数据规模
机器人：RT-1数据（13台·17个月，回合数按RT-1论文约 130k）；网络：将WebLI约 10B图像-文本对（109种语言）筛选前10%得1B示例 + 字幕·VQA数据集；机器人占比约 50%（PaLI-X）·约 66%（PaLM-E）
主要数据集
RT-1数据;WebLI;字幕·VQA数据集
任务·评估
真实机器人评估6k次；训练任务200个以上，泛化任务280个以上；Language-Table仿真；涌现能力评估
机器人
与RT-1相同的移动操作机器人(办公室厨房)

将预训练VLM与机器人数据及网络VQA·描述数据联合微调，以文本token输出动作。其256区间动作token方式被此后众多自回归VLA沿用。
备注
