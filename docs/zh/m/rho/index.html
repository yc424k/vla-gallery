备注

核心特点
在加入物理grounding的Phi系列VLM上接入542M flow matching动作专家的5B开放权重VLA，采用预训练 → 按机器人midtraining → 任务微调 → 在线校正的分阶段适配方案。将Rho-base针对YAM Box·UR AI Trainer·FR3 Duo进行midtraining的变体在相同成功率下只需一半任务数据，在3种真机上与π0.5·GR00T N1.7·MolmoAct2持平或领先。
备注
与Rho-alpha(ρα)的关系：论文·项目页·README均未提及Rho-alpha，项目负责人Andrey Kolobov的发布帖(Digg引用，二手)称Rho为'作为Rho-alpha VLA+工作基础(underlying)的开放权重5B VLA系列'；Rho-alpha博客曾预告'数月内公开技术说明'。公开：rho-base·rho-yam-box·rho-ur-ai-trainer·rho-fr3-duo·rho-libero·rho-roboeval权重(HF，MIT)，代码(GitHub MIT)，BusyBox·LIBERO·RoboEval微调数据；Rho-Tomyum预训练数据部分为未公开的自有数据。在线适配为FlowDAgger(将校正动作经冻结flow逆变换，对潜在策略做回归训练) — 仅训练潜在策略，冻结主干·动作专家。微调GPU为论文消融适配(B200 4张) vs README LIBERO复现(H100 4张) A/B。语言主干Phi-Phy由Phi系列VLM蒸馏(论文)。检查点约10.5 GB(含优化器20.6 GB)
