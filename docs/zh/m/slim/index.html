备注

核心特点
仅凭MuJoCo仿真RL(特权教师→视觉学生)训练一个四足+机械臂策略，用一台手腕RGB和语言指令完成搜索·接近·抓取·搬运·投放的长时程任务，并零样本部署到真实机器人。以不到19M参数在真实环境全部任务中取得78.3%成功率，与专家遥操作(75.0%)相当且快约1.5倍。
备注
列表外新增（2025 四足移动操作VLA）；无需真实数据·微调的零训练部署；语言编码器为无预训练LM的字节token Transformer；训练GPU 'V100或类似'；代码仅称将公开。
