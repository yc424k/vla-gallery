Qwen-RobotNav

Qwen Team · 2026-06

VLA导航4B·8B回归

备注

核心特点
将任务模式和观测上下文(token预算·时间衰减·相机权重)参数化并在训练时随机化，使一个模型作为上层智能体规划器的工具执行VLN·物体搜索·追踪·自动驾驶。用15.6M样本训练的8B取得R2R-CE SR 72.1%·RxR-CE SR 76.5%(全景)，并在Go2上以Jetson Thor端侧4.9 Hz零样本行驶。
备注
README: 'There is currently no plan to release the model weights'。延迟数值冲突: 论文为远程196 ms·端侧204 ms,README为端侧196 ms。单目结果(R2R SR 65.7%)与LightNav-0对比表一致。'真机自主驾驶日志'为车辆驾驶数据(nuScenes·OpenScene)。摘要中的2B变体不在结果表中。
