架构原文摘要
DINOv2图像编码器(22.1M) + 速度编码器 → 基于GRU的潜在状态估计·预测(自回归world model) → 与路径(route)嵌入做self-attention融合 → MLP：6维速度指令(线·角速度) + 路径5个位姿；训练时用语义·RGB(LDM)解码器监督world model

备注

核心特点
先用自回归潜在world model学习环境动力学，再在其潜在状态上分离学习动作策略，仅凭仿真数据实现泛化的端到端导航模型。在Isaac Sim仓库中成功率96%(Nav2 58%)，无需微调即零样本部署到真实Nova Carter。
备注
2阶段训练(用随机动作预训练world model → 用Nav2教师数据追加策略)。总参数·训练时间未公开。HF检查点1.44GB(x_mobility-nav2-semantic_action_path.ckpt)，Apache 2.0代码。后续COMPASS的基础策略。
