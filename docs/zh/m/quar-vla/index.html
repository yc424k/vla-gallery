备注

核心特点
提出了由单张RGB和语言指令以离散token输出四足高层指令（速度·步态·姿态）的四足VLA任务定义、QUART模型及仿真·实机QUARD数据集。通过4,000次评估表明，大规模仿真数据与少量真实数据联合训练使实机Go to成功从3/20提高到13/20。
备注
仿真数据由A*/D*路径+PD速度转换脚本生成，真实数据为远程操控；下层控制器[23]=Walk These Ways(本文未明示RL，原论文为PPO)；训练GPU·时长未注明；也比较了LLaVA-7B变体(性能相近)；v1→v6模型构成·数据数值有变化；权重未公开(QUARD在QUART-Online页面于HF公开)。
