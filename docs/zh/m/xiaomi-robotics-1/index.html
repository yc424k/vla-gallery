备注

核心特点
以超过10万小时的UMI轨迹配合VLM自动标注(场景状态转移描述)进行预训练，再用约1万小时跨本体数据对齐到机器人·指令的2阶段VLA。预训练数据·模型规模越大，未见环境的即时性能越高，RoboCasa365 57.4%·RoboDojo得分20.07，超过此前最佳(46.6%·13.07)。
备注
预训练目标为flow matching + Choice Policies回归 + 0.1×NTP(VL:UMI = 1:9)；阻止DiT看到VLM的动作token KV以切断复制捷径；状态转移描述由Qwen3.5-27B自动生成；客房级10分钟以上整理行李箱演示；代码·检查点2026-08-03公开(Apache-2.0，HF Xiaomi-Robotics-1-5B model_states.pt 10.2 GB，按基准的RoboCasa·RoboCasa365·VLABench检查点)，2B·10B未公开，预训练UMI数据未公开；arXiv v2 2026-07-22。前作：Xiaomi-Robotics-0 (arXiv 2602.12684) — 沿用异步训练方案与VL数据(论文明示)
