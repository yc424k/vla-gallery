备注

核心特点
以220万小时以上人类经验(网络·第一人称视频、LiberSense Glove手部动作、跨本体机器人数据)经视觉预测 → 视频·动作联合预测 → 聚焦操作的3阶段预训练的world action model。在无目标任务机器人演示的条件下，于GPT-6提出的60项任务(600次)中取得成功率36.0%(PnP 63.5%·短Non-PnP 34.0%·多阶段10.5%)，并报告手套数据10,000小时比多200倍的网络人类视频迁移效果更好。
备注
LiberSense Glove厚0.3 mm·重131 g，第一人称·双腕相机与手部姿态同步(不测量接触·力)；演示者1→100人(episode数固定)时仅手套进度得分12.7→40.1；'zero-shot'指无目标任务的机器人演示，预训练中包含机器人数据；性能均为自报。官方技术博客2026-11-04(新闻稿2026-11-03，ACCESS Newswire)，新闻稿中的'GPT-6 Astra 5%'在博客中为短Non-PnP 5.0%，整体数值博客中未给出(二手)。权重：博客模型本身未公开，HF公开了RoboDojo评估检查点Liber0-Preview-Robodojo(2026-10-14)·Liber0-Lite-Robodojo(2026-10-10，含pretrain/初始化权重)(许可证未注明，两个model.pt sha256相同)；Lite推理代码链接到个人账号的XPolicyLab分叉(zhangxiwen1810/XPolicyLab，liber-0分支)(是否官方未核实)。基础：World Action Models are Zero-shot Policies (arXiv 2602.15922)·Mixture-of-Transformers (博客引用)
