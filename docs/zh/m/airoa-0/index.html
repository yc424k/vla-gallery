备注

核心特点
不使用机器人数据，仅用开源手持夹爪YUBI采集的16,151小时双臂演示进行预训练·后训练，仅凭双腕两台相机即可在无训练数据的场所执行长时程·精细任务的基于π0.5的VLA。加入视觉预算门控·阶段预测·本体感知记忆·非均匀流式解码，在Franka 10项任务中平均成功率78%(π0.5·XR-1·GR00T N1.7·MolmoAct2中最高为27%)，同一权重也可在TX-G2·OpenArm·UR上运行。
备注
预训练目标为See Less, Specify More(S2)：flow matching动作损失 + 视觉预算损失 + 子任务文本预测辅助损失(仅训练用)，以任务·子任务两级指令为条件；状态为以一只夹爪为基准的另一只夹爪位姿 + 双夹爪开合(11维)，不使用机器人基座·关节·世界坐标；后训练损失为动作 + 0.1×预算 + 0.1×阶段 + 0.01×子任务；权重以HF门控(Gemma Terms of Use)公开 — pretrained + 后训练示例3个(orange_pyramid·towel_folding·letter_blocks，20k步EMA)，每个检查点约12 GB(bf16约6.7 GB)；后训练代码在GitHub(Apache-2.0，基于OpenPI，JAX)；16,151小时数据集已宣布公开，但项目页面为'Coming soon'(2026-11-13确认)；明示未使用遥操作·强化学习·机器人现场校正·仿真；NEDO项目JPNP25015。基础：π0.5: a Vision-Language-Action Model with Open-World Generalization (arXiv 2504.16054) — 由π0.5 base检查点初始化并直接沿用主干(论文明示)
