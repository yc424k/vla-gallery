架构原文摘要
以LingBot-VLA-2.0初始化：Qwen3-VL-4B-Instruct理解主干(图像边长256px，patch 16·2×2 merge，语言72 token) + token级MoE动作专家(36层，每层routed expert 32个top-4 + shared expert，总计6B) → flow matching去噪10步 → 双臂16维(每臂关节7 + 末端执行器1)动作块50步；动作·状态在55维槽位中补零后选取活跃16通道，辅助损失为深度·未来帧(各0.004)

备注

核心特点
将通用VLA LingBot-VLA-2.0收窄到Kuavo4pro单一机型和工业现场单一环境，用同机型真机遥操作100项任务680小时再训练的领域专用基础模型(DSFM)。在相同的按任务20个epoch后训练条件下，将工业20项任务平均成功率从LingBot-VLA-2.0的14.0%提升至49.7%，25项任务整体从16.3%提升至48.3%。
备注
数据仅使用经4阶段质量管理(采集·标注·审核·批准)和自动轨迹过滤的成功演示，以行为克隆训练；第1阶段检查点选择在无真机结果的情况下固定为最后一个epoch(报告称离线action MSE与真机性能不一致)。权重在HF·ModelScope·OpenLET公开，但HF为申请审批制(gated)，模型许可证未注明；数据集按任务分批公开(HF Apache-2.0)；代码LeTools-Learning(GPL-3.0)，2026-08-26公开(README)。报道中写作'600小时以上'的数据量按一手来源为680小时。基础: LingBot-VLA-2.0 (报告[24]) — 以其为初始值进行领域再训练(报告明示)
