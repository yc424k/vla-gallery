OmniVLA

UC Berkeley·Toyota Motor North America·Princeton University · 2025-09

VLA导航7.5B回归

可单独或组合接收语言·目标图像·2D目标位置的全模态导航VLA，以10个平台9,500小时数据对OpenVLA 7B进行LoRA训练。

备注

核心特点
可单独或组合接收语言·目标图像·2D目标位置的全模态导航VLA，以10个平台9,500小时数据对OpenVLA 7B进行LoRA训练。在真实机器人上语言目标成功率0.73(LeLaN 0.43)·2D位置0.95·目标图像1.00，与各模态专用策略持平或更高。
备注
用LoRA将训练参数限制在约5%。FrodoBots·BDD-V用MBRA,LeLaN用NoMaD合成动作标签。HF页面自动标注'8B params'(论文7.5B),BF16 safetensors约15.1GB。训练时间·推理延迟未公开。ICRA 2026。基础: OpenVLA: An Open-Source Vision-Language-Action Model (arXiv 2406.09246) — 从OpenVLA 7B检查点开始训练,基于OpenVLA-OFT代码库 (README)
