架构原文摘要
SigLIP(so400m)图像·文本编码器 + Lift3D式点云tokenizer(LoRA) → 按语言-视觉余弦相似度对2D·3D token加权 → DiT动作头(官方代码：RDT-1B配置hidden 2048·28层，RDT-1B初始化)；以预训练移动头(DiT 170M)的潜在底盘表征为条件生成全身动作；底盘速度(绝对) + 臂关节(仿真中为相对变化)，动作块2(仿真)，DDPM推理5步(代码)

核心特点
将先用底盘动作单独训练的轻量移动头的潜在表示作为全身动作生成的条件（mobility-to-body），并按各阶段需要调节2D图像与3D点云的权重。在ManiSkill-HAB上高于RDT·DP·3DP，在真实Cobot Magic的4项长时程任务上超过ACT·π0。
