备注

核心特点
在Fuyu-8B中以稀疏MoE加入多个LoRA专家，把VLA视为Q函数，用成功·失败混合的自动采集数据做离线RL训练的四足VLA。6项技能仿真平均成功率0.60，领先QUART(0.44)等基线，加入失败数据经RL提升了性能。
备注
专家数·LoRA rank·Top-K值未注明；'冻结主干·仅训练LoRA'的描述与FFN→MoE转换的描述并存；稀疏奖励(成功时为1)+保守正则化(α=0.5)；推理速度未注明；无代码·权重公开链接。基于：GeRM: A Generalist Robotic Model with Mixture-of-experts for Quadruped Robot (arXiv 2403.13358) — 直接沿用GeRM的Q函数学习损失与QUARD-Auto数据(同一团队的四足MoE模型)
