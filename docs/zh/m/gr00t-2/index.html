GR00T 2

NVIDIA (GEAR) · 2026-11

기타2026年新增2B Transformer视频world model

用人类第一人称视频·UMI演示·多种机器人遥操作预训练以联合预测未来多视角视频与动作的2B world action model，展示了将人类·UMI演示技能迁移到无演示机器人的X-Adapt。

架构原文摘要
由Cosmos-Predict2.5-2B视频diffusion transformer初始化的单个2B Transformer将视频·状态·动作token作为一个序列处理：冻结Wan 2.1 VAE(时间4×·空间8×，224×320下每潜在帧·每相机token 280个，最多4相机·5 fps·0.8秒历史) + 冻结Cosmos-Reason1文本编码器(交叉注意力) + 各本体状态·动作MLP与动作解码器 → 用flow matching联合生成未来视频潜变量与动作块(动作token注意到正在生成的未来帧)，部署时视频1~2·动作2~4去噪步；动作块48步(1.6秒@30 Hz，YAM·Dexter)，G1 Turbo为80步

备注

核心特点
用人类第一人称视频·UMI演示·多种机器人遥操作预训练以联合预测未来多视角视频与动作的2B world action model，展示了将人类·UMI演示技能迁移到无演示机器人的X-Adapt。在Dexter-50未训练任务中零样本40%，演示1条71%·5条95%(RTX 5090 1张LoRA约30分钟)，并通过真机GRPO后训练将接触任务成功率提升到88~98%。
备注
GR00T 2 Turbo：用Wan 2.2 VAE将空间压缩由8×提至16×(潜在网格缩小4倍)，动作块长度相同，在YAM V2上与GR00T 2无统计学差异，同时每次调用快约3倍(RTX 5090 52 vs 171 ms)，灵巧手任务由68.6%→34.3%下降；在G1上输出SONIC(PPO训练的全身控制器)动作token·夹爪宽度。后训练RL：rollout时仅对动作去噪施加CPS噪声，记忆过往回报的GRPO式目标(AutoRL智能体在仿真中探索约35天)，GRPO成功rollout自模仿，冻结策略之上的residual RL，DreamDojo world model内RL。支持面向智能体的WAM API(MCP)·code-as-policy·视觉引导，数据标注用Flora。代码'计划12月公开'(项目页面)，截至2026-11-13 GitHub NVIDIA/Isaac-GR00T为N1.7，HF nvidia/下无GR00T 2权重。Human-1M-100K已在HF公开。2026-11-09于CoRL发布(NVIDIA博客'开放frontier world action model')，arXiv版未核实
