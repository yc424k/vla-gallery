备注

核心特点
通过将点跟踪轨迹作为图像提示输入的visual trace prompting提升时空感知。在SimplerEnv 137种设置中达到47.7%，超过OpenVLA(40.2%)。
备注
用轨迹标注数据继续训练OpenVLA，因此没有单独的机器人预训练。参数(B)以7B变体为准。有一次提取结果显示v3 PDF所属机构中也有Capital One†。
