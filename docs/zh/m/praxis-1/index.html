Runway · 2026-11

架构原文摘要
将Runway视频基础模型(DDT结构：条件编码器14块 + velocity解码器6块diffusion transformer，FFN 20层中17层为MoE(共享1 + routed 128中top-8)，26.9B·每token激活约2.8B)改为chunk-causal注意力，在冻结的Wan2.2 VAE潜空间和冻结的Qwen3.5-2B文本编码器上运行 → 独立dense 16层宽1024动作expert(约314M，以交叉注意力读取主干编码器8个层) → 视频·动作rectified flow联合去噪(Euler 2步) → 通过按本体的轻量输入输出投影输出动作块24行(1.6秒@15 Hz；DROID 10维EE位姿·夹爪，YAM 20维)和未来视频块

备注

核心特点
在以网络·第一人称视频预训练的27B MoE视频diffusion transformer上接入小型动作expert，以1.6秒动作块为单位同时预测未来视频与动作的world action model。DROID微调版在NVIDIA RoboLab-120上取得46.2%(1,200次中555次)，在world action model·开源机器人基础模型中排名第1，并在训练数据中未出现的RT-1上微调后取得SimplerEnv 80.0%(RT-1原策略52.4%)。
备注
首次发布2026-09-30(研究博客'Introducing Praxis-1'，合作方先行公开)，2026-11-11公开权重·技术报告(Apache 2.0，允许商用)。HF runwayml/：praxis-1-base·-droid·-yam·-so101及NVFP4版(-droid·-yam·-so101-nvfp4)·LeRobot版(-base·-droid·-yam-lerobot)，访问同意门控(自动批准)，bf16检查点17分片约54 GB；GitHub runwayml/praxis-1-oss(推理·策略服务器·MuJoCo仿真·全量/LoRA微调代码)，LeRobot内置适配器，支持vLLM-Omni·Reactor托管·NeMo Automodel后训练。训练使用Muon(大部分矩阵) + AdamW(嵌入·头·投影·路由器)，仅冻结文本编码器·VAE，视频·动作velocity损失等权重。RTC为可选(默认执行整个动作块)，双臂停顿时间32%→5%。冻结视频基础的成功预测头(AUROC 0.77)为未公开早期版本的研究结果。RoboLab-120中高于Praxis-1的4个为LLM智能体(AMP1 86.0%·SenseNova-RoboRSI 57.1%)与非公开模型(Lakeside 51.0%·BiMind v0.5 49.2%)。局限：混淆相似物体、模糊指令、单一指令多阶段任务。无arXiv版(未核实)。基础: Runway视频基础模型(DDT结构，Wang et al. 2025)，动作expert与DeVA相似(报告明示)
