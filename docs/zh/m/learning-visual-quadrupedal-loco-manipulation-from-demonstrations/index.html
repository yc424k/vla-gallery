备注

核心特点
由一只前足跟踪参数化贝塞尔轨迹、其余三条腿行走的RL底层控制器，与输出轨迹参数的基于点云的DP3 diffusion规划器构成的分层腿部操作策略。无需机械臂、仅靠腿部即在仿真与真实机器人(Aliengo)上完成按按钮·推门·移动中提篮子等。
备注
演示并非人类遥操作，而是由RL控制器在仿真中跟踪设计好的专家轨迹参数生成；规划器不直接输出底盘速度，而以世界坐标目标(在4 m×4 m范围内训练)引导移动；无真实机器人定量结果；代码·权重未公开。基础：3D Diffusion Policy: Generalizable Visuomotor Policy Learning via Simple 3D Representations (arXiv 2403.03954) — 以DP3作为高层规划器主干(论文明示)
