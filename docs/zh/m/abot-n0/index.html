备注

核心特点
以将LLM Brain与flow matching Action Expert组合的Brain-Action结构,把点·物体·指令·POI·跟人5项导航任务统一到一个VLA中,并用16.9M专家轨迹·5.0M推理样本数据引擎和SAFE-GRPO RL训练。在7个基准(R2R-CE SR 66.4%,SocNav闭环SR 88.3%等)上声称SOTA,并在Go2的Jetson Orin NX上以2 Hz机载运行。
