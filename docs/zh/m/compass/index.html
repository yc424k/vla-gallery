备注

核心特点
在基于模仿学习的策略之上训练各具身的残差RL专家，再将其蒸馏为一个具身条件策略，统一轮式·四足·人形机器人导航。在仿真基准上成功率比X-Mobility提高约5倍（例：H1 22.0%→84.4%），在Jetson AGX Orin上以29 ms运行。
备注
初版仅在图1说明中提及真实世界部署并将Sim2Real列为后续工作，但v3(2025-10)新增Carter·Unitree G1实机部署(Jetson Orin，20次成功率约80%)。HF(nvidia/COMPASS，需申请)公开了Carter用ONNX·JIT策略与GR00T后训练资料，多embodiment generalist检查点未在文件列表中确认。提供用蒸馏数据为GR00T VLA添加导航能力的工作流(官方文档)。参数·训练时间未公开。NVIDIA Open Model License。基于：X-MOBILITY: End-To-End Generalizable Navigation via World Modeling (arXiv 2410.17491) — 将X-Mobility固定为基础策略使用 (论文·HF卡片明确说明)
