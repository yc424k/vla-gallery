核心特点
在LingBot-VLA基础上改进，用20种机器人配置的轨迹50,000小时和第一人称人类视频10,000小时、共约60,000小时进行预训练，并将头部·腰部·移动底盘·手部自由度统一纳入55维动作空间。在动作专家中加入sparse MoE，并将当前·未来查询蒸馏到LingBot-Depth·DINO-Video，以未来预测作为辅助任务学习。
备注
子任务标注由Qwen3.6-27B自动生成(18个原子动作词表)；人类视频通过SLAM·手部姿态估计恢复MANO手部轨迹；ablation报告相对关节动作优于绝对关节、MeanStd归一化、L2(MSE) flow matching效果更好；预训练采用loss-free MoE负载均衡(DeepSeek-V3式偏置)，后训练config使用序列辅助损失·z-loss；代码·权重(robbyant/lingbot-vla-v2-6b，RoboTwin后训练版lingbot-vla-v2-6b-robotwin) Apache-2.0，有LeRobot转换版(lerobot/lingbot_vla_v2_base)；arXiv v1 2026-07-07。基础：A Pragmatic VLA Foundation Model (arXiv 2601.18692) — 改进自前一版本LingBot-VLA(论文明示)
