备注

核心特点
不给预训练VLM加新头，仅添加指点token与RVQ动作token，将指令跟随·物体搜索·视觉跟踪统一为单一token接口，并按ER中期训练→SFT→GRPO RL顺序训练。仅用单目RGB即在10个公开仿真设置中取得单目方法最高成功率(R2R-CE SR 68.5%，EVT-Bench STT SR 91.7%)，并零样本迁移到人形·四足·飞行·轮式机器人。
