Architecture (original summary)
OpenVLA 7B (Llama 2-7B + DINOv2·SigLIP, 7.5B total) takes current·goal images, 2D goal position, language input (goal combinations masked via modality dropout) → linear action head on LLM output (OpenVLA-OFT style) regresses 8 waypoints (3 Hz, 2.4 s) → linear·angular velocity commands; lightweight OmniVLA-edge 50M (ViNT-based, EfficientNet-B0·CLIP·FiLM)

Notes

Key features
An omni-modal navigation VLA taking language·goal images·2D goal positions alone or combined, LoRA-trained from OpenVLA 7B on 9,500 h of data from 10 platforms. On real robots, language-goal success 0.73 (LeLaN 0.43)·2D position 0.95·goal image 1.00, equal to or above modality-specific policies.
Notes
LoRA limits trained parameters to about 5%. FrodoBots·BDD-V use MBRA, LeLaN uses NoMaD synthetic action labels. HF page auto-label '8B params' (paper 7.5B), BF16 safetensors about 15.1GB. Training time·inference latency not disclosed. ICRA 2026. Based on: OpenVLA: An Open-Source Vision-Language-Action Model (arXiv 2406.09246) — training starts from the OpenVLA 7B checkpoint, based on the OpenVLA-OFT codebase (README)
