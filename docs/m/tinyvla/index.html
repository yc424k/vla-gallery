Notes

Key features
Attaches a diffusion head to a small VLM without robot-data pretraining and trains with LoRA (5.0% of transformer parameters). Latency on A6000 is 14 ms, about 1/20 of OpenVLA (292 ms).
Notes
A diffusion-head VLA rather than an autoregressive token model, but included since it is in the assigned scope. Only the base VLMs (about 400M/700M/1.3B) are released on HF; no policy checkpoint was found. Code released 2025-02-17. Parameters (B) based on the largest variant, TinyVLA-H.
