Notes

Key features
Attaches object instructions to YouTube tour·human walking videos and robot driving data with SAM·VLM (CogVLM)·GPT-3.5, labels object positions with depth estimation, and trains a language-conditioned object navigation policy. Real-world zero-shot success rate 0.89 beat modular baselines such as OWL-v2+ZoeDepth (0.67)·CoW (0.58), and it runs at 0.054 s per action on Jetson Orin.
Notes
