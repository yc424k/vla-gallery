Notes

Key features
An end-to-end navigation model that first learns environment dynamics with an autoregressive latent world model, then separately trains an action policy on its latent state, generalizing from sim data alone. It reached 96% success in an Isaac Sim warehouse (Nav2 58%) and was deployed zero-shot on a real Nova Carter without fine-tuning.
Notes
2-stage training (world model pretrained on random actions → policy added with Nav2 teacher data). Total parameters and training time not disclosed. HF checkpoint 1.44GB (x_mobility-nav2-semantic_action_path.ckpt), Apache 2.0 code. Base policy for the follow-up COMPASS.
