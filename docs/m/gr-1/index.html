Notes

Key features
Pretrained by future-frame prediction on large-scale human video, then jointly learns actions and future images on robot data. A language-conditioned GPT-style policy without an LLM·VLM backbone that improved CALVIN performance.
Notes
The industry note classifies it as VLA (by language input), a different criterion from the note that puts RT-1 under the same conditions as VA. Full Ego4D is over 3,500 h, of which GR-1 used 800K clips. CALVIN ABCD-D·ABC-D fine-tuned checkpoints released (Apache-2.0).
