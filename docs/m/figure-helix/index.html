Notes

Key features
Projects the S2 latent vector into the S1 token space, concatenates it with visual features, and trains a single set of weights end-to-end with a regression loss. The laundry·dishwasher updates only added data, without model·hyperparameter changes.
Notes
Parameters (B) is the sum of 7B + 80M. The S1 vision backbone is initialized from sim pretraining, and S1/S2 inputs are offset in time by the deployment latency. The logistics update (2025-06-07) added Vision Memory, state history, and force feedback. Go-Big (2025-09-18) learned language-instructed navigation from 100% egocentric human video. 2025 locomotion is a separate RL controller (separate row). Helix 02 (2026-01) is out of scope.
