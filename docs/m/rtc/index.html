Key features
Simulates inference latency during training (uniformly sampled 0–10 steps on hardware) to learn action-prefix conditioning, so there is no extra compute from inference-time RTC. On box assembly and espresso it matched inference-time RTC with lower latency.
Notes
Type is Other since it is a fine-tuning technique based on π0.6. Supports up to 200 ms latency on a 50 Hz robot. Simulation samples latency {0..4} with exponentially decaying weights.
