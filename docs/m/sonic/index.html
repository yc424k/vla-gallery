Architecture (original summary)

Notes

Key features
A general token-based whole-body controller that scales motion tracking in data·model·compute. Scaling an MLP (instead of a transformer) from 1.2M to 42M raised test-content success from 98.0% to 99.6%.
Notes
Data hours are the v1 in-house dataset of 700 hours (611 hours after retargeting in the latest version). GPU-hours conflict across versions: v1 abstract 9k vs v1 §2.1 32,000 ('128 GPUs over 3 days'); the latest version trains 16·32·128 GPUs all to 50k iterations, giving about 2k·9k·21k. VLA data 3,900 trajectories (13 objects × 300)·multi-object 1,000 trajectories†; v1-line PDF fine-tunes GR00T N1.5 with 300 teleoperation demonstrations. No weights at 2025 release; checkpoints 2026-02-19·training code 2026-04-10 (weights NVIDIA Open Model License, code Apache 2.0). The 2026 training guide recommends 64+ GPUs (not a 2025 paper value). v4 2026-08-13 (Science Robotics 11(117) eaed4592). Kinematic planner is 'Transformers or Conv1D'.
