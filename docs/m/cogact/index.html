Notes

Key features
A separate DiT generates action sequences conditioned on the cognition token from the VLM, and Adaptive Action Ensemble merges chunks. At 7.6B it achieved SIMPLER Google Robot VM 74.8% and a Realman real-robot average of 71.2%.
Notes
The original does not state which DiT size the 7.6B refers to (default action module is DiT-Base). The note's 'Franka 30K checkpoint' is a baseline (Octo · OpenVLA) value and was removed; CogACT tested only a single 10K-step checkpoint. Largest DiT is 308M in the table/300M in the body. Checkpoint 30 GB.
