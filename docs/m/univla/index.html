Notes

Key features
Learns latent actions in two stages, task-agnostic and task-centric, so even human video and navigation data can be used for pretraining. Pretraining took 960 A100-hours, about 5% of OpenVLA.
Notes
The Bridge-only and human-video-only variants use 8 GPUs, global batch 258 (as written in the original), about 200 A100-hours. The latent action model uses batch 512 · 100k steps; time not disclosed. Domains also include navigation (R2R). A different model from BAAI's UniVLA.
