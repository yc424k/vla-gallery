Notes

Key features
A VLA that runs the VLM only as a semantic cache refreshed every 0.5~2 s, while the action expert handles 50 ms-period control using the measured cache age and fresh low-latency video tokens. Training with cache ages sampled from real episode histories and age-proportional pixel occlusion restored LIBERO-Spatial success at 2 s refresh from 61.4% to 95.5%, and a forward-only chunk-boundary correction (soft-nudge) reached 97.1% with replanning at every control step.
Notes
The fast encoder is pretrained with masked reconstruction (about 49% band masking) + WAFT optical flow + Depth Anything V2 depth teachers, then frozen; frame interval δ=0.2 s; cache age injected as a log(1+τ) sinusoidal embedding through a zero-initialized projection, Δmax=2 s; cache refresh by period·events (frame difference·gripper·subtask)·episode reset (reported experiments use only period·reset); soft-nudge is a forward-only correction that replaces the Jacobian transpose in RTC guidance with the identity, leaving the TensorRT/NPU export graph unchanged; a CoT verdict gate blocks 166/180 instruction-scene mismatch episodes while keeping 20/20 feasible tasks; real robots use a 1:4 semantic refresh; release of the asynchronous evaluation protocol is only mentioned, no code·weights links; a separate model from MERL's identically named LEAP-VLA (InternVL3-1B, GitHub AndersonYu7/LEAP-VLA). Based on: π0 (arXiv 2410.24164) — follows the shared-attention coupling of a VLM prefix and a flow matching action expert (stated in paper)
