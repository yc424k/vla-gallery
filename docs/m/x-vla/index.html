Notes

Key features
Absorbs heterogeneity across 7 platforms with per-embodiment soft prompts (0.04% of all parameters). Tuning only 1% of parameters (9M) with LoRA reached LIBERO 93%, and it won 1st place at AgiBot World Challenge @ IROS 2025.
Notes
Google Robot scores: paper 80.4/75.7 vs README 83.5/76.4. LIBERO-Long uses 97.6, consistent with the 98.1 average. Accepted at ICLR 2026 (README). App. K lists baseline retraining compute (A100×4 about 60 h·150,000 steps, π0 LoRA A800×4 about 7 h·30,000 steps).
