VBC (Visual Whole-Body Control)

UC San Diego · 2024-03

VAMobile manipulationNot disclosedRL policy

A hierarchical quadruped+arm whole-body control framework in which a visual high-level policy outputs base velocity and end-effector pose targets that an RL low-level policy using the leg joints tracks.

Notes

Key features
A hierarchical quadruped+arm whole-body control framework in which a visual high-level policy outputs base velocity and end-effector pose targets that an RL low-level policy using the leg joints tracks. A privileged-state RL teacher is DAgger-distilled into a depth-based student, grasping objects of various heights·shapes on the real robot without real data collection·fine-tuning.
Notes
In real-robot evaluation a human specifies the target object mask with TrackingSAM; real-robot success rates shown only in plots; '81.87' in the teacher table is as written in the source; only code and low-level weights released (GitHub), high-level weights not released; CoRL 2024 Oral.
