Notes

Key features
A two-stage-trained whole-body control framework in which two RL policies, a locomotion policy and an arm policy, cooperate (the arm policy commands body pitch·roll) to perform quadruped+arm base movement and end-effector 6D pose tracking simultaneously. Showed 23% higher task success than baselines and zero-shot cross-embodiment transfer from Go1 to Go2.
Notes
A proprioceptive RL controller with no visual input; in experiments base velocity·end-effector pose are commanded by VR teleoperation (Meta Quest 3) (no high-level learned policy); the calculation basis of 23% vs 39/60 and 32/60 is unclear; the paper lists the affiliation as 'University of San Diego' (project page: UC San Diego); code (based on Walk These Ways)·deployment code released, weights not released; RA-L 2025. Based on: Walk These Ways: Tuning Robot Control for Generalization with Multiplicity of Behavior (arXiv 2212.03238) — README states the base implementation was borrowed from walk-these-ways
