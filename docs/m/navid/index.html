Architecture (original summary)
EVA-CLIP vision encoder + instruction-queried tokens · instruction-agnostic tokens (64 for the current frame, 4 per past frame) + Vicuna-7B (based on LLaMA-VID); outputs the next single action as text (FORWARD + distance, TURN-LEFT/RIGHT + angle, STOP), extracted by a regex parser; monocular RGB video input only, 1.2–1.5 s per action

Notes

Key features
A video-VLM-based VLN agent that outputs the next action as language from monocular RGB video history and language instructions only, operating in continuous environments (VLN-CE) without maps·odometry·depth. Co-trained on 510k sim samples and 763k web data, it reached R2R-CE SR 37.4% and showed sim-to-real generalization in a real-robot test of 200 indoor instructions.
Notes
The README's released checkpoint (HF Jzzhang/NaVid, CC BY-NC 4.0) is a version retrained on R2R·RxR training splits following the Uni-NaVid training strategy, with R2R val SR 41.9%·RxR val SR 45.7% (README table), differing from paper numbers; evaluation code released; pretraining field refers to the NaVid training stage after LLaMA-VID initialization (only LLaMA·text encoder trained); batch·learning rate not disclosed; RSS 2024. Based on: LLaMA-VID: An Image is Worth 2 Tokens in Large Language Models (arXiv 2311.17043) — the paper states it builds on the video VLM LLaMA-VID
