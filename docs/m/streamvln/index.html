Architecture (original summary)
Multi-turn conversational streaming based on LLaVA-Video 7B (LLM Qwen2-7B); fast: sliding-window KV cache reuse of the last N turns, slow: 3D voxel-based token pruning memory; outputs discrete action text each turn (↑ forward 25 cm·←/→ turn 15°·STOP, 4 by default in code)

Notes

Key features
A streaming VLN model that processes continuous video as a multi-turn dialogue, reusing recent turns via a sliding-window KV cache and compressing past visual information into a 3D voxel-based token-pruning memory. It keeps latency low on long videos, reached R2R-CE SR 56.4% (extra VLN data), and executed indoor·outdoor instructions on a real Unitree Go2.
