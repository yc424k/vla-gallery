Architecture (original summary)
System 2: Qwen2.5-VL-7B takes past·current RGB and instructions and outputs an in-image pixel goal (or learned latent plan tokens)·stop·turn in place at 2 Hz / System 1: NavDP-style diffusion policy (DepthAnything RGB encoder, with critic; DualVLN uses DiT 12 layers·hidden 384) generates short-horizon trajectories at 30 Hz (DualVLN 32 dense waypoints) → MPC tracking, low-level controller 200 Hz

Notes

Key features
An asynchronous dual-system navigation foundation model where a VLM-based System 2 outputs in-image pixel goals·latent plans at low frequency and a diffusion-based System 1 generates high-frequency trajectories conditioned on them. Trained on sim-only InternData-N1 (53.5M images·4,839.9 km), it achieves state of the art on VLN-CE·VLN-PE and transfers zero-shot to wheeled·quadruped·humanoid real robots.
Notes
Announcement based on creation of the HF InternVLA-N1-Preview repository (2025-07-21); technical report 2025-09-11, DualVLN paper arXiv 2512.08186 (2025-12); HF variants: Preview (synchronous, about 2 Hz) → wo-dagger (renamed first official release) → w-NavDP*·DualVLN (recommended, RGB only); training GPU·time Not disclosed; data scale stated variously as 50M+/53M/53.5M; license CC BY-NC-SA 4.0; training code released 2025-12. Based on: NavDP: Learning Sim-to-Real Navigation Diffusion Policy with Privileged Information Guidance (arXiv 2505.08712) — the report states System 1 inherits a structure similar to NavDP
