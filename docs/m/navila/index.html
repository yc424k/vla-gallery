Notes

Key features
A two-stage design where the VLA outputs mid-level language actions with distances·angles instead of low-level joint commands, and an RL locomotion policy using a LiDAR height map executes them with obstacle avoidance. Trained on data including 20K trajectories built from 2K YouTube tour videos, it reaches R2R-CE SR 54.0% and 88% success on 25 real-world instructions.
Notes
LLM·vision encoder names not stated in the paper; based on README checkpoint names (navila-siglip-llama3-8b-v1.5-pretrain, navila-llama3-8b-8f); VILA stages 1·2 (connector initialization 4 hours·VL pretraining 30 hours) inherited; RL locomotion policy control frequency not stated (LiDAR 15 Hz); weights·training code·data annotations released (YouTube originals as video IDs only); RSS 2025. Based on: VILA: On Pre-training for Visual Language Models (arXiv 2312.07533) — the paper states it builds on VILA and inherits stages 1·2 from VILA
