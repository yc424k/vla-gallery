Notes

Key features
A dexterous manipulation VLA that places a Multi-Stream Action Transformer, receiving motion perception·long-term memory·physical sensing (tactile·torque) each as a dedicated stream, on top of a VLM based on Qwen3-VL 8B. Trained in 3 stages, pretraining→per-embodiment mid-training→per-task post-training (optional RECAP RL), it averaged 86.8% on 48-DoF ALLEX humanoid tasks (π0.5·GR00T N1.6 about 40%), and static graphs·kernel fusion cut it to 43.7 ms per step on an RTX 5090.
Notes
