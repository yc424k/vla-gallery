AC-DiT

Peking University·Nanjing University·CUHK·Beijing Academy of Artificial Intelligence(BAAI) · 2025-07

VLAMobile manipulationNot discloseddiffusion

Feeds the latent representation of a lightweight mobility head, pretrained on base actions alone, as a condition for whole-body action generation (mobility-to-body), and adjusts the weights of 2D images and 3D point clouds according to each stage's needs.

Architecture (original summary)
SigLIP (so400m) image·text encoder + Lift3D-style point cloud tokenizer (LoRA) → weights 2D·3D tokens by language-vision cosine similarity → DiT action head (official code: RDT-1B config hidden 2048·28 layers, RDT-1B init); generates whole-body actions conditioned on latent base representation from pretrained mobility head (DiT 170M); base velocity (absolute) + arm joints (relative change in sim), chunk 2 (sim), DDPM inference 5 steps (code)

Key features
Feeds the latent representation of a lightweight mobility head, pretrained on base actions alone, as a condition for whole-body action generation (mobility-to-body), and adjusts the weights of 2D images and 3D point clouds according to each stage's needs. Scored higher than RDT·DP·3DP on ManiSkill-HAB and beat ACT·π0 on 4 real Cobot Magic long-horizon tasks.
Notes
Paper does not state training·inference hardware or total parameters; RDT-1B initialization·steps·batch follow official GitHub scripts.
