Notes

Key features
A navigation foundation model trained as one model on multiple embodiments (quadrupeds·drones·wheeled·vehicles etc.) and VLN·object search·tracking·autonomous driving tasks, introducing viewpoint·time instruction tokens and token-budget-based history sampling. With 8.02M navigation samples and no per-task fine-tuning, it was best or competitive on R2R-CE (4-view SR 61.7%)·RxR-CE·HM3D-OVON·EVT-Bench·NAVSIM etc.
Notes
Inference GPU differs between the paper (RTX 4090) and the project page (RTX 5090); autonomous-driving data are real vehicle driving logs (nuScenes, OpenScene), with no real-robot training data collected; no public code or weights link (per project page); ICLR 2026.
