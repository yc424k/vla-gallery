Notes

Key features
Attaches a DiT flow-matching decoder to a Qwen VLM, unifying manipulation·navigation·trajectory prediction in one action·trajectory space, with per-robot prompt conditioning so one set of weights handles multiple embodiments. A single generalist model scores LIBERO 97.9%·R2R-CE SR 57.5%·RxR-CE SR 59.6% and averages 83.6% on real ALOHA (π0.5 71.6%).
Notes
No real mobile base control experiments: navigation is evaluated only in VLN-CE R2R/RxR sim and the real robot is a fixed ALOHA, so as instructed it is listed as 'New in 2026'·base 'Fixed'.
