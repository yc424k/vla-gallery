Architecture (original summary)
RGB encoded by pretrained DepthAnything ViT, depth by a from-scratch ViT → Transformer decoder compresses 512 RGB-D tokens into 16 fused tokens → 2-layer Transformer encoder (shared by policy·critic) → conditional U-Net·DDPM diffusion head generates a batch of 24-step waypoints (Δx,Δy,Δω), critic (trajectories encoded by 1D conv) scores them to select the best trajectory; linear·angular velocity computed from trajectory midpoint×proportional gain, >10 Hz

Notes

Key features
Using only simulation data, jointly trains trajectory generation (diffusion) and trajectory evaluation (critic) from RGB-D observations in one transformer; the critic is trained on contrastive negative trajectories built from sim privileged information (global ESDF). Without real-robot data it transfers zero-shot to quadruped·wheeled·humanoid robots, and adding Gaussian Splatting real-to-sim data (about 4k trajectories) raises real-world success from 50% to 80%.
Notes
Training GPU, time, steps, batch, and parameter count all not disclosed (text and appendix). Conflicting data scale: text, PDF, and HF abstract say 363.2 km and 1,244 scenes, while current arXiv abstract metadata says 'over 1 million m and 3,000 scenes'.
