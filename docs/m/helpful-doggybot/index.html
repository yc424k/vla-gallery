Notes

Key features
Modular indoor object-fetching system for a Go2 with a front-bottom 1-DoF gripper, combining an egocentric depth-based agile controller trained with sim RL and pretrained VLM perception with proportional control. Without collecting or training on real data, it achieved 60–70% success in two unseen homes, including climbing onto a bed to fetch a toy.
Notes
Only the low-level RL controller is learned; detection and tracking use pretrained models, and motion and grasp commands use rule-based proportional control (linear velocity fixed at 0.8 m/s); reliance on a ceiling camera stated as a limitation; natural-language object specification via Florence-2 prompts; code released (GitHub), weights not released.
