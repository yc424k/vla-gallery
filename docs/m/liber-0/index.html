Architecture (original summary)
World Action Model: language·vision·action experts combined via Mixture-of-Transformers jointly predict future frames and actions through multimodal attention; a shared Physical Encoder takes state·Unified Embodiment Representation (human·robot morphology·kinematics)·noisy actions; semantic co-training on VQA·segmentation·image editing·video understanding; for multi-step tasks a reasoning agent such as GPT-6 Astra optionally plans subgoals. Notes

Key features
A world action model pretrained in 3 stages — visual prediction → joint video·action prediction → manipulation focus — on over 2.2 million hours of human experience (web·egocentric video, LiberSense Glove hand motion, cross-embodiment robot data). Without robot demonstrations for the target tasks, it reached 36.0% success (PnP 63.5%·short Non-PnP 34.0%·multi-step 10.5%) on 60 tasks (600 trials) proposed by GPT-6, and reports that 10,000 hours of glove data transfers better than 200× more web human video.
Notes
LiberSense Glove is 0.3 mm thick·131 g, synchronized with egocentric·both-wrist cameras and hand pose (contact·force not measured); going from 1 to 100 demonstrators (episode count fixed) raises glove-only progress score from 12.7 to 40.1; 'zero-shot' means no robot demonstrations for the target tasks, while pretraining includes robot data; all performance is self-reported. Official technical blog 2026-11-04 (press release 2026-11-03, ACCESS Newswire); the press release's 'GPT-6 Astra 5%' is short Non-PnP 5.0% in the blog, and the overall figure is not in the blog (secondary). Weights: the blog model itself is Not disclosed; RoboDojo evaluation checkpoints Liber0-Preview-Robodojo (2026-10-14)·Liber0-Lite-Robodojo (2026-10-10, including pretrain/ initialization weights) released on HF (license not stated, both model.pt files have the same sha256); Lite inference code links to an XPolicyLab fork on a personal account (zhangxiwen1810/XPolicyLab, liber-0 branch) (official status Unverified). Based on: World Action Models are Zero-shot Policies (arXiv 2602.15922)·Mixture-of-Transformers (cited in blog)
