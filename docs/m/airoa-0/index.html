Notes

Key features
A π0.5-based VLA pre- and post-trained solely on 16,151 hours of bimanual demonstrations collected with the open-source handheld gripper YUBI, with no robot data, that performs long-horizon·precise tasks in locations without training data using only two wrist cameras. Adding a visual budget gate·stage prediction·proprioceptive memory·non-uniform streaming decoding, it reached a 78% average success rate on 10 Franka tasks (best of π0.5·XR-1·GR00T N1.7·MolmoAct2: 27%), and the same weights run on TX-G2·OpenArm·UR.
Notes
Pretraining objective is See Less, Specify More (S2): flow matching action loss + visual budget loss + subtask text prediction auxiliary loss (training only), conditioned on two levels of task·subtask instructions; state is the other gripper's pose relative to one gripper + both grippers' open/close (11-dim), using no robot base·joint·world coordinates; post-training loss is action + 0.1×budget + 0.1×stage + 0.01×subtask; weights released gated on HF (Gemma Terms of Use) — pretrained + 3 post-training examples (orange_pyramid·towel_folding·letter_blocks, 20k-step EMA), about 12 GB per checkpoint (bf16 about 6.7 GB); post-training code on GitHub (Apache-2.0, based on OpenPI, JAX); the 16,151-hour dataset was announced for release but the project page says 'Coming soon' (checked 2026-11-13); explicitly uses no teleoperation·reinforcement learning·on-robot calibration·sim; NEDO project JPNP25015. Based on: π0.5: a Vision-Language-Action Model with Open-World Generalization (arXiv 2504.16054) — initialized from the π0.5 base checkpoint and uses its backbone as is (stated in paper)
