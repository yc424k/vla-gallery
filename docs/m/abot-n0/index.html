Notes

Key features
Unifies 5 navigation tasks (point·object·instruction·POI·person following) in one VLA with a Brain-Action architecture combining an LLM Brain and a flow matching Action Expert, trained with a data engine of 16.9M expert trajectories·5.0M reasoning samples and SAFE-GRPO RL. Claims SOTA on 7 benchmarks (R2R-CE SR 66.4%, SocNav closed-loop SR 88.3%, etc.) and runs onboard at 2 Hz on Go2's Jetson Orin NX.
Notes
README·paper make no mention of weight·code release (README has only paper·project page, marked Apache 2.0). Conflicting scene area: paper 10.7 km² vs README 10.3 km². Some documents say 'ABot-NO'. The low-level Neural Controller is a CE-Nav-based VelFlow expert fine-tuned with Isaac Sim RL. Training compute·total parameters not disclosed.
