Notes

Key features
A 5B open-weight VLA that attaches a 542M flow matching action expert to a Phi-family VLM with added physical grounding, using a staged adaptation recipe of pretraining → per-robot midtraining → task fine-tuning → online correction. Variants of Rho-base midtrained for YAM Box·UR AI Trainer·FR3 Duo reach the same success rate with half the task data, and match or beat π0.5·GR00T N1.7·MolmoAct2 on 3 real robots.
Notes
Relation to Rho-alpha (ρα): the paper·project page·README do not mention Rho-alpha; project lead Andrey Kolobov's announcement post (quoted by Digg, secondary) describes Rho as 'the open-weight 5B VLA family underlying the Rho-alpha VLA+ work'; the Rho-alpha blog had promised 'a technical description within months'. Released: rho-base·rho-yam-box·rho-ur-ai-trainer·rho-fr3-duo·rho-libero·rho-roboeval weights (HF, MIT), code (GitHub MIT), BusyBox·LIBERO·RoboEval fine-tuning data; part of the Rho-Tomyum pretraining data is private in-house data. Online adaptation is FlowDAgger (corrective actions are inverted through the frozen flow and a latent policy is trained by regression) — only the latent policy is trained, backbone·action expert frozen. Fine-tuning GPUs: paper ablation adaptation (4 B200) vs README LIBERO reproduction (4 H100) A/B. Language backbone Phi-Phy is distilled from a Phi-family VLM (paper). Checkpoint about 10.5 GB (20.6 GB with optimizer)
