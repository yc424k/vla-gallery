Architecture (original summary)
Initialized from LingBot-VLA-2.0: Qwen3-VL-4B-Instruct understanding backbone (image side 256px, patch 16·2×2 merge, 72 language tokens) + token-level MoE action expert (36 layers, 32 routed experts top-4 + shared expert per layer, 6B total) → flow matching 10 denoising steps → bimanual 16 dims (7 joints + 1 end-effector per arm) chunk of 50 steps; actions·states 0-padded into 55-dim slots then 16 active channels selected, auxiliary losses depth·future frames (0.004 each)

Notes

Key features
A domain-specific foundation model (DSFM) that narrows the generalist VLA LingBot-VLA-2.0 to a single platform, Kuavo4pro, and a single industrial setting, retrained on 680 hours of same-platform real-robot teleoperation across 100 tasks. Under the same per-task 20-epoch post-training, it raised average success on 20 industrial tasks from LingBot-VLA-2.0's 14.0% to 49.7%, and across all 25 tasks from 16.3% to 48.3%.
Notes
Data uses only successful demos that passed 4-stage quality control (collection·annotation·review·approval) and automatic trajectory filters, trained by behavior cloning; stage 1 checkpoint selection fixed to the last epoch without real-robot results (reports that offline action MSE did not match real-robot performance). Weights are released on HF·ModelScope·OpenLET, but HF requires approved access (gated), model license not stated; the dataset is released task by task (HF Apache-2.0); code LeTools-Learning (GPL-3.0), released 2026-08-26 (README). The data volume reported as 'over 600 hours' in the press is 680 hours per primary sources. Based on: LingBot-VLA-2.0 (report [24]) — domain retraining from it as initialization (stated in report)
