Architecture (original summary)
Qwen3-VL-4B/8B (vision tower frozen) + frozen VGGT spatial encoder (mid-layer tokens, 2048 dims per patch → RMSNorm·2-layer MLP merger, added to visual tokens with α=0.2) → 4 heads on LLM hidden states (autoregressive action policy, inverse dynamics classification, forward dynamics MLP, future spatial feature generation); inference uses only the policy head, one discrete text action (STOP·MOVE_FORWARD·TURN_LEFT·TURN_RIGHT) per step

Notes

Key features
Brings world-action modeling to VLN, jointly learning action prediction, inverse·forward dynamics, and future spatial state generation on VLM hidden states, while using only the policy head at inference to keep speed. With monocular RGB·4B backbone it reaches R2R-CE SR 65.4%·RxR-CE SR 60.9%, outperforming prior VLN models such as 7B-class JanusVLN (R2R 60.5%).
