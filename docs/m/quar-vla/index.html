Notes

Key features
Proposed the quadruped VLA task definition, in which quadruped high-level commands (velocity·gait·pose) are output as discrete tokens from a single RGB image and language instruction, along with the QUART model and the sim·real-robot QUARD dataset. 4,000 evaluations showed that co-training on large-scale sim data and a small amount of real data raised real-robot Go to success from 3/20 to 13/20.
Notes
Sim data generated by an A*/D* path + PD velocity conversion script; real data by remote control; low-level controller [23] = Walk These Ways (this paper does not state RL; the original paper uses PPO); training GPU·time not stated; a LLaVA-7B variant was also compared (similar performance); model configuration·data numbers changed across v1→v6; weights not released (QUARD released on HF via the QUART-Online page).
