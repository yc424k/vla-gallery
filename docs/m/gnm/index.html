Notes

Key features
Unifies heterogeneous driving data from 6 robots with a normalized action space and temporal context to train a single image-goal-conditioned navigation policy. Drove 4 robots, including a Tello quadrotor unseen in training, without per-robot fine-tuning, and in some cases performed up to 5× better than single-dataset policies.
Notes
Data hours mismatch: 60h in main text vs 70h in Table I; dataset count also differs (8/9). Parameter count is not in the GNM paper but given as 8.7M in the appendix of the same group's ViNT paper. Small/Mid/Large differ in the number of datasets used (2/4/6), not model size. Checkpoints released on Google Drive; code merged into visualnav-transformer (README gives a LoCoBot+Jetson Orin Nano deployment example). ICRA 2023.
