Notes

Key features
A humanoid latent-predictive world action model that predicts future observation embeddings from language·egocentric/third-person video·proprioception while generating SONIC-compatible whole-body action latents with an action DiT. On 11 real-world household loco-manipulation tasks it reached 81.8% success, far ahead of baselines such as ψ-0 (44.5%)·π0.5 (27.3%).
Notes
Public human motions converted into robot-executable action latents·states via SONIC sim replay, with tracking-failure trajectories removed; teleoperation drives SONIC with Pico 4 Ultra·Pico trackers; chunk 25 (paper) vs 30 in public config; code (GitHub MIT, HF card Apache-2.0)·weights (keycharon/Omega-zero)·ω-HOME (HF 38.2GB) released; arXiv v2 2026-08-09. Based on: SONIC: Supersizing Motion Tracking for Natural Humanoid Whole-Body Control (arXiv 2511.07820) — executes via SONIC action latent space·controller and latentizes public motions via SONIC replay (stated in paper)
