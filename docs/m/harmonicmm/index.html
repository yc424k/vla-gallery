Notes

Key features
Trains a single policy end-to-end with DD-PPO in ProcTHOR sim that moves base and arm together from RGB alone, without separating navigation and manipulation modules. Averaged 47% success on 4 sim tasks, beating baselines such as ReLMoGen, and performed door opening·table cleaning in unseen real apartments without fine-tuning.
Notes
Pre-2024 reference baseline (anchor). A separate policy per task with no language or goal input. The vision encoder is a ViT (DINOv2) but the policy trunk is a GRU, so classified as non-Transformer. Real-robot door handle grasping is heuristic-assisted. Code released (GitHub), no checkpoints. IROS 2024 Best Paper on Mobile Manipulation.
