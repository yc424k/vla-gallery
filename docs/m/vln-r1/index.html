Notes

Key features
Applies SFT to a general VLM (Qwen2-VL) for egocentric-video-based VLN, then improves multi-step action prediction via GRPO reinforcement fine-tuning (RFT) with a time-decayed reward (TDR). The 2B model after RFT outperformed a 7B model with SFT only, showing the effect of RL post-training even for small VLMs.
