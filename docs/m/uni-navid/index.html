Notes

Key features
Unifies the input/output format of 4 navigation tasks (VLN·ObjectNav·EQA·human following) to train a single video VLA, achieving about 5 Hz non-blocking real deployment with online token merging and 4-step action prediction. Through cross-task synergy on 3.6M navigation samples, it reported state of the art at the time on multiple benchmarks, including R2R-CE SR 47.0% and HM3D ObjectNav SR 73.7%.
Notes
Public weights (HF Jzzhang/Uni-NaVid, uninavid-7b-full-224-video-fps-1-grid-2) are an open-source version with some features rewritten due to licensing and do not use L3MVN data for ObjectNav; README table R2R val SR 51.8%·RxR val SR 56.1% differ from paper figures; training·evaluation code released; batch·learning rate not disclosed; RSS 2025.
