Notes

Key features
A test-time computation hierarchical VLA whose high-level policy, with execution memory, uses a world model to predict outcome videos of candidate subtasks and a value model to score them for beam search. The low-level policy trained on 40,115 hours of real data reaches an average SR of 27.5% on 4 long-horizon tasks (π0.5 22.5%), and the hierarchical system (Plan Once) raises it to 45.0%.
Notes
Low-level policy 3-stage training (KI co-training → end-to-end co-training → per-task adaptation); Gemma4-31B-it used for high-level data labeling; public HF weights are the low-level pretrained policy (not a zero-shot controller, for post-training), high-level Proposal·World Model released separately (2026-09); HF release 2026-07-27, arXiv v1 2026-08-17; code·weights Apache-2.0, example data CC BY-NC-SA 4.0
