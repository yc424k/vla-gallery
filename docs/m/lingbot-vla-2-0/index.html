Notes

Key features
Improves on LingBot-VLA, pretraining on 50,000 hours of trajectories from 20 robot configurations plus 10,000 hours of egocentric human video, about 60,000 hours in total, and handles head·waist·mobile base·hand DoF in a 55-dim unified action space. Adds sparse MoE to the action expert and learns future prediction as an auxiliary task by distilling current·future queries from LingBot-Depth·DINO-Video.
Notes
Subtask annotations auto-generated with Qwen3.6-27B (vocabulary of 18 atomic actions); human video MANO hand trajectories recovered via SLAM·hand pose estimation; ablations report relative joint actions over absolute joints, MeanStd normalization, and L2 (MSE) flow matching work better; pretraining uses loss-free MoE load balancing (DeepSeek-V3-style bias), post-training config uses sequence auxiliary loss·z-loss; code·weights (robbyant/lingbot-vla-v2-6b, RoboTwin post-trained lingbot-vla-v2-6b-robotwin) Apache-2.0, LeRobot conversion (lerobot/lingbot_vla_v2_base) available; arXiv v1 2026-07-07. Based on: A Pragmatic VLA Foundation Model (arXiv 2601.18692) — improves on the previous LingBot-VLA (stated in paper)
