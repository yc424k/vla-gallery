Notes

Key features
A quadruped VLA that inserts many LoRA experts into Fuyu-8B as a sparse MoE, treats the VLA as a Q-function, and trains it with offline RL on auto-collected data mixing successes and failures. Its average sim success over 6 skills was 0.60, ahead of baselines such as QUART (0.44), and adding failure data improved performance through RL.
Notes
Number of experts, LoRA rank, and Top-K value not stated; descriptions of 'frozen backbone, LoRA-only training' and of converting FFN→MoE are mixed; sparse reward (1 on success) + conservative regularization (α=0.5); inference speed not stated; no public code or weights link. Based on: GeRM: A Generalist Robotic Model with Mixture-of-experts for Quadruped Robot (arXiv 2403.13358) — reuses GeRM's Q-function training loss and QUARD-Auto data as is (quadruped MoE model from the same group)
