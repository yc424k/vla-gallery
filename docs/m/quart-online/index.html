Notes

Key features
A quadruped VLA that removes latency without shrinking parameters by fine-tuning an MLLM, with ACD compressing continuous action chunks into residual VQ codes, to output multi-step commands in one inference. Matching QUART (previously 2 Hz) to the 50 Hz low-level control rate, it raised task success rate by 65%.
Notes
Shows sharp success drops when shrinking parameters (5.3B, 2.7B) (0.74→0.22, 0.11) and proposes ACD as an alternative; no real-robot details; batch (256 vs 128) and parameters (8B vs 9B) differ by source; code (MIT), weights, and QUARD data released on HF; ICRA 2025 (project page). Based on: QUAR-VLA: Vision-Language-Action Model for Quadruped Robots (arXiv 2312.14457) — low-latency successor to the 2 Hz QUART (stated in the paper), uses QUARD data
