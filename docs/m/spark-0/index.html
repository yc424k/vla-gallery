Notes

Key features
A VTLA model that supervises visual tokens only during training with contact maps from tactile gloves and frozen Depth-Anything-3 features, while a separate tactile pathway conditions only the action expert on per-region force history and 3D taxel states. A single checkpoint supports both vision-only and tactile-conditioned deployment, and 1,000 hours of HumanTouch tactile pretraining raises Ego Humanoid vision-only success from 52.5% to 71.7% and SparkArena-Real success from 44.0% to 52.0%.
Notes
Sampling weights HumanTouch 0.35·EgoDex 0.39·same-glove robot 0.09; human data retargeted to WUJI hands via IK; state·action 58-dim (paper) vs 54-dim (README) A/B, RTC replanning interval 24 steps (paper) vs 16 steps (README) A/B; code (GitHub MIT)·pretrained checkpoint pretrain_spark_0 (HF, 400k steps .pt about 10.9GB)·SparkArena released, fine-tuned checkpoints·HumanTouch data release not stated; also integrated into XPolicyLab.
