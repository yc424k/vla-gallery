Notes

Key features
Navigation VLA with adaptive CoT that turns on explicit reasoning only when needed and a memory combining language summaries and key visual features; post-trained with expert-guided online RL after imitation learning. Reports HM3Dv2 ObjectNav SR 83.0% and state-of-the-art EVT-Bench and Instance ImageNav, transferring zero-shot to Unitree Go2.
Notes
Additional model: ByteDance Seed's 2026 navigation VLA, included for combining adaptive CoT, language memory, and online RL post-training and reporting state-of-the-art ObjectNav, tracking, and ImageNav; name of the LLM inside LLaVA-Video-7B not stated in the paper (the StreamVLN paper lists Qwen2-7B); number of waypoints n not stated; training duration not disclosed; weights and code not released (project page only); no VLN-CE results.
