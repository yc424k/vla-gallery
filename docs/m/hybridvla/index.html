Notes

Key features
One LLM does both autoregressive prediction and diffusion action generation, using a collaborative ensemble that averages the two actions when mean AR token confidence exceeds 0.96. Pretrained on 760K trajectories from 35 datasets for over 10K A800 GPU-hours.
