Architecture (original summary)
Training-free three-stage translation: Language Action (Gemini-3.1-Pro; Qwen3.5-27B/9B-Q4 on real robots) picks a direction (forward, left, right, back) and tool calls (turn, backtrack, stop, etc.) → Vision Action (Qwen3.5-27B) marks a bbox/point on the view at the chosen moment → Robot Action back-projects it to a 3D point, then FMM (sim)/NavDP (real robot) path → per-robot controllers; discrete ground motion in sim (0.25 m forward, 30° turns), UAV (x,y,z) waypoints

Notes

Key features
A training-free agent in which a pretrained MLLM picks a direction in language and points to a target pixel visually, which is translated into robot actions; adding TODO List Memory and Second Chance Backtrack, it handles 4 task families·4 robot types with one structure. Without training on robot data, it reached R2R-CE SR 60.7%·HM3D-v2 ObjectNav SR 77.7%, matching or beating trained navigation foundation models.
Notes
No trained weights of its own (training-free framework): main sim results rely on the closed Gemini-3.1-Pro API, while VA Qwen3.5-27B, real-robot Qwen3.5 Q4, and low-level NavDP are open weights, hence marked 'Partial'. Code released (CC BY-NC-SA 4.0). The three real ground robots use NavDP instead of FMM for the Robot Action stage. Institution Beihang University per the project page author listing. Extends the prior work LaViRA (zero-shot VLN-CE). Based on: LaViRA: Language-Vision-Robot Actions Translation for Zero-Shot Vision Language Navigation in Continuous Environments (arXiv 2510.19655) — the official code README states 'This work builds on LaViRA', and the project page says 'Previously on LaViRA'
