Key features
Collects demonstrations without a robot using a handheld gripper with a GoPro and transfers them to robot policies. Matches sensor and robot latencies; 3 demonstrators collected 1,400 demos in 12 person-hours at 30 locations.
Notes
Gripper BoM $73, GoPro·accessories $298; 155° fisheye lens·side mirrors·IMU-aided ORB-SLAM3. In-the-wild cup checkpoint (fine-tuned CLIP ViT-L) released. Repository default config (120 epochs, batch 64) differs from the paper's per-task settings.
