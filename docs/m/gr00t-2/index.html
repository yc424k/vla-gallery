Architecture (original summary)
A single 2B Transformer initialized from the Cosmos-Predict2.5-2B video diffusion transformer processes video·state·action tokens in one sequence: frozen Wan 2.1 VAE (temporal 4×·spatial 8×, 280 tokens per latent frame·camera at 224×320, up to 4 cameras·5 fps·0.8 s history) + frozen Cosmos-Reason1 text encoder (cross-attention) + per-embodiment state·action MLPs and action decoder → jointly generates future video latents and action chunks via flow matching (action tokens attend to the future frames being generated), 1~2 video·2~4 action denoising steps at deployment; action chunk 48 steps (1.6 s @ 30 Hz, YAM·Dexter), 80 steps for G1 Turbo

Notes

Key features
A 2B world action model pretrained on egocentric human video·UMI demonstrations·multi-robot teleoperation to jointly predict future multi-view video and actions, demonstrating X-Adapt, which transfers skills from human·UMI demonstrations to robots without demonstrations. On unseen Dexter-50 tasks it scored 40% zero-shot, 71% with 1 demonstration·95% with 5 (about 30 min of LoRA on 1 RTX 5090), and real-robot GRPO post-training raised contact-task success rates to 88~98%.
Notes
GR00T 2 Turbo: Wan 2.2 VAE raises spatial compression from 8× to 16× (latent grid 4× smaller), same action chunk length, statistically indistinguishable from GR00T 2 on YAM V2 while about 3× faster per call (RTX 5090 52 vs 171 ms), drops from 68.6% to 34.3% on dexterous-hand tasks; on G1 it outputs SONIC (PPO-trained whole-body controller) motion tokens·gripper width. Post-training RL: CPS noise only on action denoising during rollouts, GRPO-style objective that remembers past returns (found by an AutoRL agent searching in sim for about 35 days), self-imitation of successful GRPO rollouts, residual RL on top of a frozen policy, RL inside the DreamDojo world model. Supports a WAM API for agents (MCP)·code-as-policy·visual steering; data annotation by Flora. Code 'to be released in December' (project page); as of 2026-11-13, GitHub NVIDIA/Isaac-GR00T is N1.7 and HF nvidia/ has no GR00T 2 weights. Human-1M-100K released on HF.
