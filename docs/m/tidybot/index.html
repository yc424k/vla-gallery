Notes

Key features
Learns a per-task Diffusion Policy from phone teleoperation demonstrations on an omnidirectional (holonomic) powered-caster base, jointly outputting the base target pose and the arm end-effector target. It succeeded 6/10 to 10/10 on 6 tasks in real apartments, while a differential-drive-constrained policy under the same conditions reached only 4/10 on the mopping task (omnidirectional 9/10).
Notes
Paper describes the policy only as a 'diffusion policy'; architecture·frequency·latency follow the official GitHub code·README. Hardware design·teleoperation·training·control code open-sourced; weights released only for the sim sim-v1 policy checkpoint (real-task policies not released).
