Notes

Key features
Adds only pointing tokens and RVQ action tokens to a pretrained VLM, with no new head, unifying instruction following·object search·visual tracking in one token interface, trained in the order ER mid-training→SFT→GRPO RL. With monocular RGB only, it achieved the best monocular success rates on 10 public sim settings (R2R-CE SR 68.5%, EVT-Bench STT SR 91.7%) and transferred zero-shot to humanoid·quadruped·aerial·wheeled robots.
