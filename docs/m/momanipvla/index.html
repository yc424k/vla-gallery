Architecture (original summary)
OpenVLA-7B (LoRA fine-tuned) predicts end-effector waypoints from RGB·arm proprioception·language instructions → bi-level optimization: upper level chooses base waypoints, lower level chooses end-effector trajectory (reachability·smoothness·collision costs λ 10.0·1.0·0.6, Dual Annealing + SLSQP) → arm joints via Pinocchio IK; chunk·frequency not disclosed

Notes

Key features
Transfers a VLA to mobile manipulation by using bi-level optimization to find base waypoints that make the end-effector waypoints from a fixed-base pretrained VLA feasible. On OVMM it reached 15.8% success, 4.2%p above the previous best (11.6%), and real-world deployment used only 50 expert episodes.
Notes
The base is driven by optimization, not a learned policy (the learned part is OpenVLA LoRA adaptation). The abstract's '50 training cost' means 50 expert episodes per the main text; the project page says '50% training cost'. Real-data collection method Not stated.
