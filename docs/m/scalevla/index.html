Notes

Key features
A VLA that reads causal encoder features of the frozen 552B MoE VLM DeepSeek-V4.1-Flash only once per action chunk and feeds them to a 32-layer flow matching action DiT trained from scratch; compares backbones from 2B~552B with the same action head·data·budget. Achieved 87.8% on LIBERO-Goal with 10 demos, higher than the 2B backbone with 50 (85.6%), LIBERO-PRO 45.1% (smaller backbones at most 31.3%), and real-robot charger plugging 4/10→9/10, with a median of 216 ms per chunk on 4 H200.
Notes
Comparison backbones Qwen3-VL-2B/32B, Cosmos-Reason2-2B/8B/32B (all dense, served on 1 GPU); smaller backbones read features from layer round(16L/28) by the relative-depth rule; no pretrained robot action expert loaded; on the real robot all three policies use 16-step chunks·the same safety limits, and ScaleVLA has the longest latency but the shortest completion time because its insertion phase is about 30% faster (π0.5 + action head 132.0 s); code (GitHub, Apache 2.0) released, backbone uses downloaded DeepSeek open weights, no mention of releasing trained action head checkpoints. Based on: GR00T N1.7 (NVIDIA Isaac GR00T) — follows its action head architecture and trains on the Isaac GR00T environment (stated in paper·README)
