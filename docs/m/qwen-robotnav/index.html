Notes

Key features
Parameterizes task mode and observation context (token budget·temporal decay·camera weighting) and randomizes them during training, so one model performs VLN·object search·tracking·autonomous driving as tools for a high-level agent planner. The 8B trained on 15.6M samples reached R2R-CE SR 72.1%·RxR-CE SR 76.5% (panorama) and drove zero-shot on Go2 at 4.9 Hz on-device on Jetson Thor.
Notes
README: 'There is currently no plan to release the model weights'. Conflicting latency figures: paper gives remote 196 ms·on-device 204 ms, README gives on-device 196 ms. Monocular result (R2R SR 65.7%) matches the LightNav-0 comparison table. 'Real-robot autonomous driving logs' are vehicle driving data (nuScenes·OpenScene). The 2B variant in the abstract is absent from the results tables.
