Notes

Key features
Strengthens spatial grounding by co-training, in stages with the VLA, auxiliary decoders that reconstruct robot global pose·joint configuration·grasp success·target object pose·segmentation masks. Average success on ManiSkill-HAB household tasks was 0.73, 22% higher than a multi-view·depth model without auxiliary tasks (0.60) and far ahead of OpenVLA (0.04).
Notes
Sim only (the conclusion names real-world application as future work). The paper does not mention code·weight release and no repository was found by search. History length is given inconsistently as '4 timesteps' and '4 actions'. Training time·inference speed not disclosed. Compute supported by Lambda. Based on: Prismatic VLMs: Investigating the Design Space of Visually-Conditioned Language Models (arXiv 2402.07865) — uses the pretrained Prismatic VLM as backbone
