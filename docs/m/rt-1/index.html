Notes

Key features
A 35M real-robot policy conditioned on language instructions via FiLM, without a pretrained VLM. With discrete action tokens and 17 months of teleoperation data from 13 robots, it became the baseline for the later RT family.
Notes
Notes classify it as VA (language-conditioned but no pretrained VLM). Training compute is absent from all primary sources, so secondary-source compute figures are treated as unsupported. Checkpoints rt1main·rt1multirobot·rt1simreal released (Apache).
