Notes

Key features
Changes the OpenVLA fine-tuning recipe to parallel decoding·action chunks·L1 regression, raising throughput 26~43×. Raises the LIBERO average from 76.5% to 97.1%.
Notes
Included as OpenVLA's standard follow-up recipe even though it does not use tokens at inference. Parameters (B) are based on OpenVLA 7B, excluding the additional 279M/853M. The README warns to evaluate on the same GPU used for training.
