Architecture (original summary)

Notes

Key features
Trains per-embodiment residual RL experts on top of an imitation-learning-based policy, then distills them into a single embodiment-conditioned policy to unify wheeled·quadruped·humanoid navigation. Raised success about 5× over X-Mobility on sim benchmarks (e.g., H1 22.0%→84.4%) and runs in 29 ms on Jetson AGX Orin.
Notes
The initial version mentioned real-world deployment only in the Figure 1 caption and left Sim2Real as future work, but v3 (2025-10) added real-robot deployment on Carter and Unitree G1 (Jetson Orin, about 80% success over 20 trials). HF (nvidia/COMPASS, gated) provides Carter ONNX and JIT policies and GR00T post-training materials; the multi-embodiment generalist checkpoint was not found in the file list. Provides a workflow for adding navigation to the GR00T VLA with distillation data (official docs). Parameters and training time not disclosed. NVIDIA Open Model License. Based on: X-MOBILITY: End-To-End Generalizable Navigation via World Modeling (arXiv 2410.17491) — X-Mobility is used as a frozen base policy (stated in the paper and HF card)
