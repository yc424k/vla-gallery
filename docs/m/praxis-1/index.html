Architecture (original summary)
Runway video foundation model (DDT architecture: condition encoder 14 blocks + velocity decoder 6 blocks diffusion transformer, 17 of 20 FFN layers MoE (1 shared + top-8 of 128 routed), 26.9B·about 2.8B active per token) converted to chunk-causal attention, operating in the frozen Wan2.2 VAE latent space with the frozen Qwen3.5-2B text encoder → separate dense 16-layer width-1024 action expert (about 314M, reads 8 backbone encoder layers via cross-attention) → joint video·action rectified flow denoising (Euler 2 steps) → thin per-embodiment input/output projections output an action chunk of 24 rows (1.6 s@15 Hz; DROID 10-dim EE pose·gripper, YAM 20-dim) and a future video chunk

Notes

Key features
A world action model that attaches a small action expert to a 27B MoE video diffusion transformer pretrained on web·egocentric video, jointly predicting future video and actions in 1.6-second chunks. Its DROID fine-tuned version ranked 1st among world action models·open-source robot foundation models on NVIDIA RoboLab-120 with 46.2% (555 of 1,200 trials), and fine-tuned on RT-1, unseen in training, it reached SimplerEnv 80.0% (original RT-1 policy 52.4%).
Notes
First announced 2026-09-30 (research blog 'Introducing Praxis-1', early access for partners), weights·technical report released 2026-11-11 (Apache 2.0, commercial use allowed). HF runwayml/: praxis-1-base·-droid·-yam·-so101 plus NVFP4 versions (-droid·-yam·-so101-nvfp4)·LeRobot versions (-base·-droid·-yam-lerobot), access-agreement gate (auto-approved), bf16 checkpoint 17 shards about 54 GB; GitHub runwayml/praxis-1-oss (inference·policy server·MuJoCo sim·full/LoRA fine-tuning code), built-in LeRobot adapter, vLLM-Omni·Reactor hosting·NeMo Automodel post-training support. Training uses Muon (most matrices) + AdamW (embeddings·heads·projections·routers), only the text encoder·VAE frozen, video·action velocity losses weighted equally. RTC is optional (default is chunk execution), bimanual idle time 32%→5%. The frozen-video-based success prediction head (AUROC 0.77) is a research result from an unreleased earlier version. The 4 entries above Praxis-1 on RoboLab-120 are LLM agents (AMP1 86.0%·SenseNova-RoboRSI 57.1%) and closed models (Lakeside 51.0%·BiMind v0.5 49.2%). Limitations: confusing similar-looking objects, ambiguous instructions, multi-step tasks from a single instruction. No arXiv version (Unverified). Based on: Runway video foundation model (DDT architecture, Wang et al. 2025), action expert similar to DeVA (stated in report)
