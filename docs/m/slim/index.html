Notes

Key features
A quadruped+arm policy that performs long-horizon search·approach·grasp·carry·drop tasks from a single wrist RGB camera and language instructions, trained only with MuJoCo sim RL (privileged teacher→visual student) and deployed zero-shot on the real robot. With under 19M parameters it achieved a 78.3% overall real-world task success rate, comparable to expert teleoperation (75.0%) while about 1.5× faster.
Notes
