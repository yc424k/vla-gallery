Notes

Key features
A 1.5B generalist VLA based on MiniCPM-V 4.6 that evaluates LIBERO·CALVIN·RoboTwin2·RMBench all with a single set of weights, cuts visual tokens to 64 per frame, and streams history observations into context to support up to 1 minute of visual memory. Reports LIBERO 97.5·RoboTwin2 easy 91.3·hard 91.6·RMBench 53.3 (π0.5 10.4), and its H100 BF16 single-frame model forward latency is 120 ms per decision step, shorter than π0.5's 234 ms.
Notes
Inference code·integrated evaluation (LIBERO·CALVIN·RoboTwin2·RMBench)·checkpoints (HF·ModelScope) released under Apache-2.0; training code·training data·technical report not disclosed; no embodiment ID↔robot mapping for the public checkpoints (only RoboTwin=4 stated); the action head code is a 4-step iteration that directly predicts actions from an input linearly interpolated between noise and actions (training loss not stated); model card says 1.5B, and most articles also say 1.5B. Same family: MiniCPM-RobotTrack (0.9B, target-tracking VLA based on MiniCPM4-0.5B, DINOv3 ViT-S/16·SigLIP So400m encoders → waypoints, EVT-Bench STT SR 84.1·TR 89.8, DAgger-style self-evolving data, 5+ FPS·about 180 ms on Unitree Go2 EDU + Jetson Orin NX 16GB). Based on: starVLA·LeRobot (README acknowledgments) — evaluation ported from starVLA commit 631aae02
