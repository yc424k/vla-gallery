Notes

Key features
Handles goal-directed navigation and goal-free exploration in one diffusion policy via goal masking, which randomly masks the goal image. With 19M parameters it improved exploration success (98% vs 77%) and collisions (0.2 vs 1.7) over a 335M subgoal-diffusion approach.
Notes
Paper does not state action sequence length·context·resolution → per public nomad.yaml: 8 waypoints·context 3·96×96. Training GPU·time Not disclosed. Combines goal masking with the ViNT policy architecture. Weights released on Google Drive. ICRA 2024. Based on: ViNT: A Foundation Model for Visual Navigation (arXiv 2306.14846) — combines goal masking·diffusion head with the ViNT policy architecture (stated in paper)
