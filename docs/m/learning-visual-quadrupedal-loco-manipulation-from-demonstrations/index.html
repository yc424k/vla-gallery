Notes

Key features
A hierarchical leg-manipulation policy: an RL low-level controller tracks a parameterized Bézier trajectory with one front foot while walking on the other three legs, and a point-cloud-based DP3 diffusion planner outputs the trajectory parameters. Without an arm, using legs only, it pressed buttons·pushed doors·lifted baskets while moving, in sim and on a real robot (Aliengo).
Notes
Demonstrations are generated not by human teleoperation but by an RL controller tracking designed expert trajectory parameters in sim; the planner does not output base velocity directly but induces motion via world-frame targets (trained within a 4 m×4 m range); no quantitative real-robot results; code·weights not released. Based on: 3D Diffusion Policy: Generalizable Visuomotor Policy Learning via Simple 3D Representations (arXiv 2403.03954) — uses DP3 as the high-level planner backbone (stated in paper)
