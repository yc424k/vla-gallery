Key features
Converts human demonstrations collected with Skill Capture Glove into robot data via Skill Transform, training long-horizon manipulation and 3D-map-conditioned navigation in one end-to-end model without teleoperated robot trajectories. It autonomously performed a table→dishwasher task requiring 21 objects·68 precise interactions (33 types)·130+ ft of travel, and was deployed in unseen Airbnb homes.
