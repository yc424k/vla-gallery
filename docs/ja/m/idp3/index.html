備考

主な特徴
一人称3D点群拡散方策で、ヒューマノイド上半身の操作をオンボード計算のみで15 Hzで行う。人間のデータで畳み込み層がより滑らかな行動を生むという根拠からピラミッド畳み込みエンコーダを用いる。
備考
