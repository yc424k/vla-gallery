備考

主な特徴
ロボットデータなしで、オープンソースのハンドヘルドグリッパーYUBIで集めた16,151時間の双腕デモのみで事前・事後学習し、両手首カメラ2台だけで学習データのない場所で長期・精密課題を実行するπ0.5ベースのVLAである。視覚予算ゲート・段階予測・固有受容感覚メモリ・非一様ストリーミングデコーディングを加えてFranka 10課題の平均成功率78%(π0.5・XR-1・GR00T N1.7・MolmoAct2中の最高27%)を達成し、同じ重みがTX-G2・OpenArm・URでも動く。
備考
事前学習の目標はSee Less, Specify More(S2): flow matching行動損失 + 視覚予算損失 + サブタスクテキスト予測の補助損失(学習専用)、課題・サブタスク指示文の2レベル条件; 状態は一方のグリッパー基準の他方のグリッパー姿勢 + 両グリッパーの開閉(11次元)で、ロボット基底・関節・ワールド座標を使わない; 事後学習損失は行動 + 0.1×予算 + 0.1×段階 + 0.01×サブタスク; 重みはHFゲート(Gemma Terms of Use)で公開 — pretrained + 事後学習例3個(orange_pyramid・towel_folding・letter_blocks、20k ステップEMA)、チェックポイントあたり約12 GB(bf16 約6.7 GB); 事後学習コードはGitHub(Apache-2.0、OpenPIベース、JAX); 16,151時間のデータセットは公開を発表したがプロジェクトページは'Coming soon'(2026-11-13確認); テレオペレーション・強化学習・ロボット現場補正・シミュレーション不使用を明記; NEDO課題 JPNP25015。ベース: π0.5: a Vision-Language-Action Model with Open-World Generalization (arXiv 2504.16054) — π0.5 baseチェックポイントから初期化しバックボーンをそのまま使用(論文に明記)
