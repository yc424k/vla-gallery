AMAP CV Lab (Alibaba) · 2026-02

VLAナビゲーション4Bflow matching

LLM BrainとflowマッチングのAction Expertを組み合わせたBrain-Action構造で、ポイント・物体・指示・POI・人物追従の5つのナビゲーションタスクを1つのVLAに統合し、16.9Mのエキスパート軌跡・5.0Mの推論サンプルのデータエンジンとSAFE-GRPO RLで学習する。

備考

主な特徴
LLM BrainとflowマッチングのAction Expertを組み合わせたBrain-Action構造で、ポイント・物体・指示・POI・人物追従の5つのナビゲーションタスクを1つのVLAに統合し、16.9Mのエキスパート軌跡・5.0Mの推論サンプルのデータエンジンとSAFE-GRPO RLで学習する。7つのベンチマーク(R2R-CE SR 66.4%、SocNav閉ループSR 88.3%など)でSOTAを主張し、Go2のJetson Orin NX上で2 Hzでオンボード駆動する。

README・論文に重み・コード公開の言及なし(READMEは論文・プロジェクトページのみ、Apache 2.0表記)。シーン面積が食い違う: 論文10.7 km² vs README 10.3 km²。文書の一部に'ABot-NO'表記。下位のNeural ControllerはCE-NavベースのVelFlowエキスパートをIsaac Sim RLでファインチューニング。学習計算量・総パラメータは非公開。
