GR00T 2

NVIDIA (GEAR) · 2026-11

기타2026年の新モデル2B Transformer動画world model

構造の原文要約
Cosmos-Predict2.5-2B動画diffusion transformerから初期化した単一の2B Transformerが動画・状態・行動トークンを1つのシーケンスで処理: 凍結Wan 2.1 VAE(時間4×・空間8×、224×320で潜在フレーム・カメラあたりトークン280個、最大4カメラ・5 fps・0.8秒の履歴) + 凍結Cosmos-Reason1テキストエンコーダ(クロスアテンション) + エンボディメント別の状態・行動MLPと行動デコーダ → 未来の動画潜在と行動チャンクをflow matchingで共同生成(行動トークンが生成中の未来フレームまでアテンション)、配備時は動画1~2・行動2~4デノイジングステップ; 行動チャンク48ステップ(1.6秒@30 Hz、YAM・Dexter)、G1 Turboは80ステップ

備考

主な特徴
人の一人称動画・UMIデモ・複数ロボットのテレオペレーションで未来の多視点動画と行動を共に予測するよう事前学習した2B world action modelで、デモのないロボットにも人・UMIデモのスキルを移すX-Adaptを示す。Dexter-50の未学習課題でゼロショット40%、デモ1件で71%・5件で95%(RTX 5090 1枚でLoRA約30分)を記録し、実ロボットのGRPO事後学習で接触課題の成功率を88~98%に引き上げた。
備考
GR00T 2 Turbo: Wan 2.2 VAEで空間圧縮8×→16×(潜在グリッドが4倍小さい)、行動チャンク長は同じ、YAM V2でGR00T 2と統計的に区別できない一方で呼び出しあたり約3倍高速(RTX 5090 52 vs 171 ms)、器用な手の課題は68.6%→34.3%に低下; G1ではSONIC(PPO学習の全身制御器)のモーショントークン・グリッパー幅を出力。事後学習RL: ロールアウト時に行動デノイジングのみCPSノイズ、過去のリターンを記憶するGRPO型目的(AutoRLエージェントがシミュレーションで約35日探索)、GRPO成功ロールアウトの自己模倣、凍結方策上のresidual RL、DreamDojo world model内のRL。エージェント向けWAM API(MCP)・code-as-policy・視覚ステアリングをサポート、データアノテーションはFlora。コードは'12月公開予定'(プロジェクトページ)、2026-11-13時点でGitHub NVIDIA/Isaac-GR00TはN1.7、HF nvidia/にGR00T 2の重みなし。Human-1M-100KはHFで公開。2026-11-09 CoRLで発表(NVIDIAブログ'オープンfrontier world action model')、arXiv版は未確認
