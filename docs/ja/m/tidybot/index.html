備考

主な特徴
全方向(holonomic)パワードキャスターベースとスマートフォンテレオペレーションデモでタスク別のDiffusion Policyを学習し、ベース目標姿勢とアーム手先目標を同時に出力する。実際のアパート6タスクで6/10~10/10を成功し、同条件の差動駆動制約方策はモップがけタスクで4/10(全方向9/10)にとどまった。
備考
論文は方策を'diffusion policy'とのみ記述しており、構造・周波数・遅延は公式GitHubコード・README基準。ハードウェア設計・テレオペレーション・学習・制御コードはオープンソース; 重みはシミュレーションのsim-v1方策チェックポイントのみ公開(実タスク方策は非公開)。モデルサイズ・学習GPU機種・時間は非公開。ベース: Diffusion Policy: Visuomotor Policy Learning via Action Diffusion (arXiv 2303.04137) — 論文・READMEが方策学習にDiffusion Policy(real-stanford/diffusion_policyのコード)をそのまま使用
