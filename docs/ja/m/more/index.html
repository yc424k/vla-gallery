備考

主な特徴
Fuyu-8Bに多数のLoRAエキスパートを疎なMoEとして組み込み、VLAをQ関数とみなして成功・失敗が混在する自動収集データでオフラインRL学習した四足VLAである。6スキルのシミュレーション平均成功率0.60でQUART(0.44)などのベースラインを上回り、失敗データの追加がRLを通じて性能を高めた。
備考
専門家数・LoRA rank・Top-K値は記載なし; 「バックボーン凍結・LoRAのみ学習」の記述とFFN→MoE転換の記述が混在; 疎な報酬(成功時1)+保守的正則化(α=0.5); 推論速度は記載なし; コード・重みの公開リンクなし。ベース: GeRM: A Generalist Robotic Model with Mixture-of-experts for Quadruped Robot (arXiv 2403.13358) — GeRMのQ関数学習損失とQUARD-Autoデータをそのまま活用(同グループの四足MoEモデル)
