MiniCPM-RobotManip

ModelBest(面壁智能)·OpenBMB · 2026-07

VLA2026年の新モデル1.5Bflow matching

MiniCPM-V 4.6ベースの1.5B汎用VLAで、重み1セットでLIBERO・CALVIN・RoboTwin2・RMBenchをすべて評価し、フレームあたり視覚トークンを64個に減らして履歴観測をストリーミングで文脈に蓄積し、最大1分の視覚記憶をサポートするモデルである。

備考

主な特徴
MiniCPM-V 4.6ベースの1.5B汎用VLAで、重み1セットでLIBERO・CALVIN・RoboTwin2・RMBenchをすべて評価し、フレームあたり視覚トークンを64個に減らして履歴観測をストリーミングで文脈に蓄積し、最大1分の視覚記憶をサポートするモデルである。LIBERO 97.5・RoboTwin2 easy 91.3・hard 91.6・RMBench 53.3(π0.5 10.4)を報告し、H100 BF16単一フレームのモデル順伝播遅延は決定ステップあたり120 msでπ0.5の234 msより短い。
備考
Apache-2.0で推論コード・評価統合(LIBERO・CALVIN・RoboTwin2・RMBench)・チェックポイント(HF・ModelScope)を公開、学習コード・学習データ・技術レポートは非公開; 公開チェックポイントのエンボディメントID↔ロボット対応表なし(RoboTwin=4のみ明記); 行動ヘッドのコードはノイズと行動を線形補間した入力から行動を直接予測する4ステップ反復(学習損失は記載なし); モデルカードは1.5B、記事の多くも1.5B。同系列: MiniCPM-RobotTrack(0.9B、MiniCPM4-0.5BベースのターゲットトラッキングVLA、DINOv3 ViT-S/16・SigLIP So400mエンコーダ → ウェイポイント、EVT-Bench STT SR 84.1・TR 89.8、DAgger式の自己進化データ、Unitree Go2 EDU + Jetson Orin NX 16GBで5+ FPS・約180 ms)。ベース: starVLA・LeRobot (READMEの謝辞) — 評価はstarVLAコミット631aae02から移植
