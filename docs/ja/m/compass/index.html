備考

主な特徴
模倣学習ベースの方策の上にエンボディメント別の残差RLエキスパートを学習した後、それをエンボディメント条件付きの単一方策に蒸留し、車輪型・四足・ヒューマノイドのナビゲーションを統合する。シミュレーションベンチでX-Mobility比で成功率を約5倍に高め(例: H1 22.0%→84.4%)、Jetson AGX Orinで29 msで動作する。
備考
初期版は実世界デプロイを図1のキャプションでのみ言及しSim2Realを今後の課題としたが、v3(2025-10)でCarter・Unitree G1実ロボットデプロイ(Jetson Orin、20回で成功率約80%)を追加。HF(nvidia/COMPASS、ゲート付き)にCarter用ONNX・JIT方策とGR00T事後学習資料を公開、マルチエンボディメントgeneralistチェックポイントはファイル一覧で確認できず。蒸留データでGR00T VLAにナビゲーション機能を付けるワークフローを提供(公式ドキュメント)。パラメータ・学習時間は非公開。NVIDIA Open Model License。ベース: X-MOBILITY: End-To-End Generalizable Navigation via World Modeling (arXiv 2410.17491) — X-Mobilityをベース方策として固定して使用 (論文・HFカードに明記)
