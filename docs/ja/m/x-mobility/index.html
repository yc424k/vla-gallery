NVIDIA·UT Austin·UC Berkeley · 2024-10

構造の原文要約
DINOv2画像エンコーダ(22.1M) + 速度エンコーダ → GRUベースの潜在状態推定・予測(自己回帰world model) → 経路(route)埋め込みとself-attentionで融合 → MLP: 6次元速度指令(線・角速度) + 経路5ポーズ; 学習時はセマンティック・RGB(LDM)デコーダでworld modelを監督

主な特徴
自己回帰潜在world modelで環境動力学を先に学習し、その潜在状態の上で行動方策を分離して学習することで、シミュレーションデータのみで汎化するエンドツーエンドのナビゲーションモデルである。Isaac Simの倉庫で成功率96%(Nav2 58%)を示し、ファインチューニングなしで実機Nova Carterにゼロショット配備した。
備考
2段階学習(ランダム行動でworld modelを事前学習 → Nav2教師データで方策を追加)。総パラメータ・学習時間は非公開。HFチェックポイント1.44GB(x_mobility-nav2-semantic_action_path.ckpt)、Apache 2.0コード。後続COMPASSの基盤方策。
