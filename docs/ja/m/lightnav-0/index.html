Qwen3-VL-4B-Instruct(ネイティブ解像度ViT + 36層LLM)、タスク別ヘッドなしで語彙のみ拡張; ステップごとに二重チャネルのポインティングトークン2個(affordance・object) → RVQ行動トークン3個(コードブック K=256×3) → 10ステップのSE(2)ウェイポイントにデコーディング; 新しさベースの履歴圧縮; 最初のウェイポイントをロボット側MPCが追従、閉ループ約4–5 Hz

備考

主な特徴
事前学習済みVLMに新しいヘッドを加えず、ポインティングトークンとRVQ行動トークンだけを追加して指示追従・物体探索・視覚追跡を一つのトークンインターフェースに統合し、ER中間学習→SFT→GRPO RLの順に学習する。単眼RGBのみで10の公開シミュレーション設定において単眼手法として最高の成功率(R2R-CE SR 68.5%、EVT-Bench STT SR 91.7%)を達成し、ヒューマノイド・四足・飛行・車輪型ロボットにゼロショット転移した。
備考
GPU時間は2つの明示値の合算(RL段階の時間は非公開)。データ時間(h)は「4K+ hours」の下限。重み HF LightOriginsHQ/LightNav-0、コード Apache 2.0、INSIGHT-Benchは別途公開。ブログ(2026-09-01)は2,000+のインターネット実世界シーンを再利用可能なシミュレーション世界に変換したと説明。TRON 1・LightBot-0の種別分類は原文に記載なし。
