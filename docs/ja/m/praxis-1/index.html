Praxis-1

Runway · 2026-11

기타2026年の新モデル27.2B動画world model

構造の原文要約
Runway動画基盤モデル(DDT構造: 条件エンコーダ14ブロック + velocityデコーダ6ブロックのdiffusion transformer、FFN 20層のうち17層がMoE(共有1 + routed 128中top-8)、26.9B・トークンあたり活性約2.8B)をchunk-causalアテンションに変え、凍結Wan2.2 VAE潜在空間と凍結Qwen3.5-2Bテキストエンコーダで動作 → 別のdense 16層・幅1024の行動expert(約314M、バックボーンエンコーダの8層をクロスアテンションで読む) → 動画・行動rectified flowの共同デノイジング(Euler 2ステップ) → エンボディメント別の薄い入出力射影で行動チャンク24行(1.6秒@15 Hz; DROID 10次元EE姿勢・グリッパ、YAM 20次元)と未来動画チャンクを出力

推論デバイス・速度

備考

主な特徴
Web・一人称動画で事前学習した27B MoE動画diffusion transformerに小さな行動expertを付け、未来の動画と行動を1.6秒のチャンク単位で同時に予測するworld action modelである。DROIDファインチューニング版がNVIDIA RoboLab-120で46.2%(1,200回中555回)を記録し、world action model・オープンソースのロボット基盤モデルの中で1位となり、学習データになかったRT-1にファインチューニングしてSimplerEnv 80.0%(RT-1元方策52.4%)を達成した。
備考
初発表は2026-09-30(研究ブログ「Introducing Praxis-1」、パートナーへの先行公開)、2026-11-11に重み・技術レポートを公開(Apache 2.0、商用利用可)。HF runwayml/: praxis-1-base・-droid・-yam・-so101およびNVFP4版(-droid・-yam・-so101-nvfp4)・LeRobot版(-base・-droid・-yam-lerobot)、アクセス同意ゲート(自動承認)、bf16チェックポイント17シャード約54 GB; GitHub runwayml/praxis-1-oss(推論・方策サーバ・MuJoCoシミュレーション・全体/LoRAファインチューニングコード)、LeRobot内蔵アダプタ、vLLM-Omni・Reactorホスティング・NeMo Automodel事後学習に対応。学習はMuon(大半の行列) + AdamW(埋め込み・ヘッド・射影・ルーター)、テキストエンコーダ・VAEのみ凍結、動画・行動のvelocity損失は同じ重み付け。RTCは任意(デフォルトはチャンク実行)、双腕の停止時間32%→5%。凍結動画ベースの成功予測ヘッド(AUROC 0.77)は非公開の旧バージョンの研究結果。RoboLab-120でPraxis-1より高い4つはLLMエージェント(AMP1 86.0%・SenseNova-RoboRSI 57.1%)と非公開モデル(Lakeside 51.0%・BiMind v0.5 49.2%)。限界: 似た物体の混同、曖昧な指示、単一指示の多段階課題。arXiv版なし(未確認)。ベース: Runway動画基盤モデル(DDT構造、Wang et al. 2025)、行動expertはDeVAに類似(レポートに明記)
