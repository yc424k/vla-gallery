ViNT

UC Berkeley · 2023-06

VAナビゲーション31M回帰

GNMデータ混合を拡張したマルチロボット走行データで31M Transformer方策を学習し、目標トークンをGPS座標・経路指令など他の目標モダリティ用のsoft promptに置き換えて適応する。

構造の原文要約
EfficientNet-B0観測エンコーダ + 観測・目標チャネル結合(early fusion)の目標エンコーダ → デコーダ型Transformer 4層・4ヘッド(512次元、過去5+現在の観測トークン + 目標トークン) → MLP: 相対ウェイポイント5個 + 時間的距離; 85×64 RGB; 4 Hzで実行・PD追従; 探索時は318M画像拡散モデルがsubgoalを提案 + トポロジカルグラフ

備考

主な特徴
GNMデータ混合を拡張したマルチロボット走行データで31M Transformer方策を学習し、目標トークンをGPS座標・経路指令など他の目標モダリティ用のsoft promptに置き換えて適応する。拡散subgoal提案とグラフ探索を組み合わせてキロメートル規模の探索を行い、学習データになかったGo1四足・LoCoBotでもゼロショットで動作した。
