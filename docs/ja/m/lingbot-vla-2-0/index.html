LingBot-VLA 2.0

Robbyant (Ant Group) · 2026-07

VLA2026年の新モデル約6.38Bflow matching

LingBot-VLAを改良し、ロボット20種構成の軌跡50,000時間と一人称の人の動画10,000時間、計約60,000時間で事前学習し、頭部・腰・移動ベース・手の自由度まで55次元の統合行動空間で扱う。

備考

主な特徴
LingBot-VLAを改良し、ロボット20種構成の軌跡50,000時間と一人称の人の動画10,000時間、計約60,000時間で事前学習し、頭部・腰・移動ベース・手の自由度まで55次元の統合行動空間で扱う。アクションエキスパートにsparse MoEを入れ、現在・未来クエリをLingBot-Depth・DINO-Videoで蒸留して未来予測を補助タスクとして学習する。
備考
サブタスク注釈はQwen3.6-27Bで自動生成(18個の原子行動語彙); 人の動画はSLAM・手姿勢推定でMANOの手軌跡を復元; 絶対関節より相対関節行動、MeanStd正規化、L2(MSE) flow matchingが良かったとのablation報告; 事前学習はloss-free MoE負荷分散(DeepSeek-V3式バイアス)、事後学習configはシーケンス補助損失・z-lossを使用; コード・重み(robbyant/lingbot-vla-v2-6b、RoboTwin事後学習版lingbot-vla-v2-6b-robotwin) Apache-2.0、LeRobot変換版(lerobot/lingbot_vla_v2_base)あり; arXiv v1 2026-07-07。ベース: A Pragmatic VLA Foundation Model (arXiv 2601.18692) — 前バージョンのLingBot-VLAを改良(論文に明記)
