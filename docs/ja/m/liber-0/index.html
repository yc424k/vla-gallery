備考

主な特徴
220万時間以上の人間の経験(Web・一人称動画、LiberSense Gloveの手の動作、クロスエンボディメントのロボットデータ)で、視覚予測 → 動画・行動の共同予測 → マニピュレーション集中の3段階事前学習を経たworld action modelである。対象課題用のロボットデモなしに、GPT-6が提案した60課題(600回)で成功率36.0%(PnP 63.5%・短いNon-PnP 34.0%・多段階10.5%)を達成し、グローブデータ10,000時間が200倍多いWebの人間動画よりよく転移すると報告した。
備考
LiberSense Gloveは厚さ0.3 mm・重さ131 g、一人称・両手首カメラと手の姿勢を同期(接触・力は未測定); デモ実施者1→100名(エピソード数固定)でグローブ専用の進捗スコア12.7→40.1; 'zero-shot'は対象課題用のロボットデモがないという意味で、事前学習にはロボットデータを含む; 性能はすべて自己報告。公式技術ブログ2026-11-04(プレスリリース2026-11-03、ACCESS Newswire)、プレスリリースの'GPT-6 Astra 5%'はブログ上の短いNon-PnP 5.0%で、全体の数値はブログにない(二次情報)。重み: ブログのモデル自体は非公開、HFにRoboDojo評価チェックポイントLiber0-Preview-Robodojo(2026-10-14)・Liber0-Lite-Robodojo(2026-10-10、pretrain/初期化重みを含む)を公開(ライセンスは記載なし、2つのmodel.pt sha256が同一); Lite推論コードは個人アカウントのXPolicyLabフォーク(zhangxiwen1810/XPolicyLab、liber-0ブランチ)へのリンク(公式かどうか未確認)。ベース: World Action Models are Zero-shot Policies (arXiv 2602.15922)・Mixture-of-Transformers (ブログ引用)
