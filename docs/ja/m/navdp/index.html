構造の原文要約
RGBは事前学習DepthAnything ViT、深度はスクラッチViTでエンコード → TransformerデコーダがRGB-D 512トークンを16個の融合トークンに圧縮 → 2層Transformerエンコーダ(方策・critic共有) → 条件付きU-Net・DDPM diffusionヘッドが24ステップのウェイポイント(Δx,Δy,Δω)をバッチ生成、critic(軌跡は1D convでエンコード)がスコア付けして最良軌跡を選択; 軌跡の中間点×比例係数で線速度・角速度を算出、>10 Hz

備考

主な特徴
シミュレーションデータのみで、RGB-D観測からの軌跡生成(diffusion)と軌跡評価(critic)を一つのTransformerで同時に学習し、criticはシミュレーションの特権情報(大域ESDF)で作った対照負例軌跡で学習する。実ロボットデータなしで四足・車輪型・ヒューマノイドにゼロショット転移し、Gaussian Splattingによるreal-to-simデータ(約4k軌跡)を加えると実環境の成功率が50%から80%に上がる。
備考
学習GPU・時間・ステップ・バッチ・パラメータ数すべて非公開(本文・付録)。データ規模の矛盾: 本文・PDF・HF要旨は363.2 km・1,244シーン、現在のarXiv要旨メタデータは「100万m以上・3,000シーン」。チェックポイントはGoogle Form申請後に提供(README上InternVLA-N1 System-1モデル)、コードCC BY-NC-SA 4.0。RL事後学習版X-NavDP(2607.28560)は別論文。
