Qwen-RobotNav

Qwen Team · 2026-06

VLAナビゲーション4B・8B回帰

タスクモードと観測コンテキスト(トークン予算・時間減衰・カメラ重み)をパラメータ化して学習時にランダム化し、1つのモデルがVLN・物体探索・追跡・自動運転を上位エージェントプランナーのツールとして実行する。

構造の原文要約
Qwen3-VL(4B・8B; SigLIP-2 ViT・2D-RoPE動的解像度・DeepStack) + 4層MLP行動ヘッド(hidden 512) → ウェイポイント8個(x,y,θ)を連続回帰(MSE); タスクモード(VLN・PointNav・ObjNav・Tracking)と視覚トークン予算(2048–4096)・時間減衰・カメラ重み・フレームサンプリングを推論時に調整、上位プランナーがツールのように呼び出す; 実配備で約5 Hz

備考

主な特徴
タスクモードと観測コンテキスト(トークン予算・時間減衰・カメラ重み)をパラメータ化して学習時にランダム化し、1つのモデルがVLN・物体探索・追跡・自動運転を上位エージェントプランナーのツールとして実行する。15.6Mサンプルで学習した8BがR2R-CE SR 72.1%・RxR-CE SR 76.5%(パノラマ)を達成し、Go2でJetson Thorオンデバイス4.9 Hzでゼロショット走行した。
備考
README: 'There is currently no plan to release the model weights'。遅延値が食い違う: 論文はリモート196 ms・オンデバイス204 ms、READMEはオンデバイス196 ms。単眼結果(R2R SR 65.7%)はLightNav-0比較表と一致。「実ロボット自律走行ログ」は車両走行データ(nuScenes・OpenScene)。要旨の2Bバリアントは結果表にない。
