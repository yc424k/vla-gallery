主な特徴
事前学習済みVLMなしで言語指示をFiLMで条件付けした35Mの実ロボット方策である。離散行動トークンとロボット13台・17か月のテレオペレーションデータにより、以後のRT系列の基準となった。
備考
ノートの分類はVA(言語条件付きだが事前学習VLMなし)。学習計算量は一次出典のどこにもないため、二次出典の計算量の数値は根拠なしとして扱う。チェックポイント rt1main・rt1multirobot・rt1simreal を公開(Apache)。
