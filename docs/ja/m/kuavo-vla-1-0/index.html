備考

主な特徴
汎用VLAであるLingBot-VLA-2.0をKuavo4pro 1機種と産業現場1環境に絞り込み、同機種の実機テレオペレーション100課題680時間で再学習したドメイン特化基盤モデル(DSFM)である。同じ課題別20エポックの事後学習条件で、産業20課題の平均成功率をLingBot-VLA-2.0の14.0%から49.7%に、25課題全体を16.3%から48.3%に引き上げた。
備考
データは4段階の品質管理(収集・注釈・レビュー・承認)と自動軌跡フィルタを経た成功デモのみを使い、行動クローニングで学習; 第1段階のチェックポイント選択は実機結果なしで最終エポックに固定(オフラインのaction MSEが実機性能と一致しなかったと報告)。重みはHF・ModelScope・OpenLETで公開されるが、HFは申請承認制(gated)、モデルライセンスは記載なし; データセットは課題単位で順次公開(HF Apache-2.0); コードはLeTools-Learning(GPL-3.0)、2026-08-26公開(README)。報道で「600時間以上」とされたデータ量は一次出典基準で680時間。ベース: LingBot-VLA-2.0 (レポート[24]) — これを初期値としてドメイン再学習(レポートに明記)
