備考

主な特徴
点追跡軌跡を画像プロンプトとして入れるvisual trace promptingで時空間認識を高めた。SimplerEnv 137設定で47.7%とOpenVLA(40.2%)を上回った。
備考
軌跡アノテーションデータでOpenVLAを継続学習するため、別途のロボット事前学習はない。パラメータ(B)は7B変種基準である。v3 PDFの所属にCapital Oneもあるという1回の抽出結果がある†。
