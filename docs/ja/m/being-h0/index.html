備考

主な特徴
人の手動画によるVLA事前学習、物理空間の整合、ロボットタスクの事後学習をつなぐ'physical instruction tuning'を用いる。実ロボット評価はヒューマノイドではなくFrankaアーム + Inspireハンドのため、対象範囲の境界にある。
備考
パラメータ(B)は最大バリアント14B。機関は検証でPeking Univ.・Renmin Univ.を追加して修正。サンプル数は論文内部で衝突(§5.1 165M+ vs 貢献リスト150M+)。データ時間1100は「1,100時間超」の下限値。重み1B/8B/14B・8B-Alignを2025-08-02公開、コードMIT(READMEバッジ)。
