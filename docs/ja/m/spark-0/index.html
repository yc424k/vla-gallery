備考

主な特徴
触覚グローブから得た接触マップと凍結Depth-Anything-3特徴で視覚トークンを学習時のみ監督し、別の触覚経路が領域別の力履歴と3D taxel状態で行動エキスパートのみを条件付けるVTLAモデルである。1つのチェックポイントで視覚のみ・触覚条件付きの両方の展開に対応し、1,000時間のHumanTouch触覚事前学習によりEgo Humanoidの視覚のみ成功率を52.5%から71.7%へ、SparkArena-Realの成功率を44.0%から52.0%へ高めた。
備考
サンプリング重み HumanTouch 0.35・EgoDex 0.39・同じグローブのロボット0.09; 人のデータはIKでWUJIの手にリターゲティング; 状態・行動 58次元(論文) vs 54次元(README) A/B、RTC再計画間隔 24ステップ(論文) vs 16ステップ(README) A/B; コード(GitHub MIT)・事前学習チェックポイントpretrain_spark_0(HF、400kステップ .pt 約10.9GB)・SparkArenaを公開、ファインチューニングチェックポイント・HumanTouchデータの公開有無は記載なし; XPolicyLabにも統合。ベース: StarVLA (論文 [3]) — StarVLA・XPolicyLabのコード上に構築(論文に明記)
