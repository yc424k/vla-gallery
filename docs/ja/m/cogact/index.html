備考

主な特徴
VLMが出したcognition tokenを条件に別個のDiTがアクション系列を生成し、Adaptive Action Ensembleでチャンクを統合する。7.6BでSIMPLER Google Robot VM 74.8%、Realman実機平均71.2%を達成した。
備考
7.6BがどのDiTサイズ基準かは原文で明示されていない(既定のアクションモジュールはDiT-Base)。ノートの「Franka 30Kチェックポイント」はベースライン(Octo・OpenVLA)の値のため削除; CogACTは10Kステップのチェックポイント1つのみ試験。最大DiTは表308M/本文300M。チェックポイント30 GB。
