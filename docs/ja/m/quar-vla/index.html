QUAR-VLA (QUART)

Westlake University·Zhejiang University · 2023-12

VLAモバイルマニピュレーション8B離散トークン

単一RGBと言語指示から四足の高レベル指令(速度・歩容・姿勢)を離散トークンで出力する四足VLAタスクの定義とQUARTモデル、シミュレーション・実ロボットのQUARDデータセットを提案した。

構造の原文要約
Fuyu-8B VLM(単一RGB+言語) → 256区間離散トークン: 11次元の高レベル指令(vx・vy・ωz、歩容位相3、周波数、体高、ピッチ、足間隔、足高)+終了、チャンクなし、2 Hz → Walk These Ways指令追従制御器が関節を生成

備考

主な特徴
単一RGBと言語指示から四足の高レベル指令(速度・歩容・姿勢)を離散トークンで出力する四足VLAタスクの定義とQUARTモデル、シミュレーション・実ロボットのQUARDデータセットを提案した。4,000回の評価で、大規模シミュレーションデータと少量の実データの共同学習が実ロボットのGo to成功を3/20から13/20に高めることを示した。
備考
シミュレーションデータはA*/D*経路+PD速度変換スクリプトで生成、実データは遠隔操縦; 下位制御器[23]=Walk These Ways(本論文にRLの明記なし、元論文はPPO); 学習GPU・時間は記載なし; LLaVA-7B変種も比較(性能は同程度); v1→v6でモデル構成・データ数値が変更; 重み非公開(QUARDはQUART-OnlineページからHFで公開)。
