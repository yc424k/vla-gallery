備考

主な特徴
物理グラウンディングを加えたPhi系VLMに542M flow matching行動エキスパートを付けた5BオープンウェイトVLAで、事前学習 → ロボット別midtraining → 課題ファインチューニング → オンライン補正の段階的な適応レシピを使う。Rho-baseをYAM Box・UR AI Trainer・FR3 Duo向けにmidtrainingしたバリアントは同じ成功率で課題データを半分しか使わず、実機3種でπ0.5・GR00T N1.7・MolmoAct2と同等以上である。
備考
Rho-alpha(ρα)との関係: 論文・プロジェクトページ・READMEにはRho-alphaへの言及がなく、プロジェクトリードAndrey Kolobovの発表投稿(Digg引用、二次情報)がRhoを「Rho-alpha VLA+の取り組みの基盤(underlying)となるオープンウェイト5B VLAシリーズ」と説明; Rho-alphaのブログは「数か月以内に技術説明を公開」と予告していた。公開: rho-base・rho-yam-box・rho-ur-ai-trainer・rho-fr3-duo・rho-libero・rho-roboevalの重み(HF、MIT)、コード(GitHub MIT)、BusyBox・LIBERO・RoboEvalのファインチューニングデータ; Rho-Tomyum事前学習データの一部は非公開の自前データ。オンライン適応はFlowDAgger(補正行動を凍結flowで逆変換して潜在方策を回帰学習) — 潜在方策のみ学習し、バックボーン・行動エキスパートは凍結。ファインチューニングGPUは論文のアブレーション適応(B200 4枚) vs README LIBERO再現(H100 4枚)でA/B。言語バックボーンPhi-PhyはPhi系VLMから蒸留(論文)。チェックポイント約10.5 GB(オプティマイザ込み20.6 GB)
