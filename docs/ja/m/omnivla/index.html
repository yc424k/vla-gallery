構造の原文要約
OpenVLA 7B(Llama 2-7B + DINOv2・SigLIP、総計7.5B)に現在・目標画像、2D目標位置、言語を入力(modality dropoutで目標の組み合わせをマスキング) → LLM出力の線形行動ヘッド(OpenVLA-OFT式)でウェイポイント8個(3 Hz、2.4秒)を回帰 → 線速度・角速度指令; 軽量版OmniVLA-edge 50M(ViNTベース、EfficientNet-B0・CLIP・FiLM)

備考

主な特徴
言語・目標画像・2D目標位置を単独または組み合わせで受け取るオムニモーダルなナビゲーションVLAで、OpenVLA 7Bを10プラットフォーム9,500時間のデータでLoRA学習した。実ロボットで言語目標成功率0.73(LeLaN 0.43)・2D位置0.95・目標画像1.00と、モダリティ別の専用方策と同等以上だった。
備考
LoRAで学習パラメータを約5%に制限。FrodoBots・BDD-VはMBRA、LeLaNはNoMaDによる合成行動ラベル。HFページの自動表記は'8B params'(論文7.5B)、BF16 safetensors 約15.1GB。学習時間・推論遅延は非公開。ICRA 2026。ベース: OpenVLA: An Open-Source Vision-Language-Action Model (arXiv 2406.09246) — OpenVLA 7Bチェックポイントから学習開始、OpenVLA-OFTコードベースに基づく (README)
