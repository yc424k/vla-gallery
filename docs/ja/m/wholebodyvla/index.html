強化学習・ベース

強化学習
一部 (RL下位制御器との結合) · VLAは潜在行動の教師あり学習、歩行指令はLMO RL方策が実行(H100 1枚で学習)
ベース制御
ヒューマノイド歩行 (指令・潜在 → RL歩行制御器) · VLAが上半身関節角 + 歩行指令(前後・左右・回転3軸の離散指示 + 姿勢高さ)を出力 → LMO RL方策が下半身トルク(50 Hz)
