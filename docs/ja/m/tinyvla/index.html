備考

主な特徴
ロボットデータの事前学習なしに小型VLMに拡散ヘッドを付け、LoRA(Transformerパラメータの5.0%)で学習する。A6000での遅延は14 msでOpenVLA(292 ms)の約1/20である。
備考
拡散ヘッドVLAで自己回帰トークンモデルではないが、割り当て範囲のため収録した。ベースVLM(約400M/700M/1.3B)のみHFで公開され、方策チェックポイントは確認できなかった。コード公開2025-02-17。パラメータ(B)は最大バリアントTinyVLA-H基準である。
