備考

主な特徴
実行メモリを持つ上位方策がworld modelで候補サブタスクの結果映像を予測し、価値モデルで評価してビーム探索するtest-time computation階層型VLAである。40,115時間の実データで学習した下位方策が長期課題4種で平均SR 27.5%(π0.5 22.5%)を出し、階層システム(Plan Once)は45.0%まで高めた。
備考
下位方策の3段階学習(KI共同学習 → エンドツーエンド共同学習 → 課題別適応); 上位データのラベリングにGemma4-31B-itを使用; 公開HF重みは下位の事前学習方策(ゼロショット制御器ではなく事後学習用)、上位のProposal・World Modelは別途公開(2026-09); HF公開 2026-07-27、arXiv v1 2026-08-17; コード・重み Apache-2.0、サンプルデータ CC BY-NC-SA 4.0
