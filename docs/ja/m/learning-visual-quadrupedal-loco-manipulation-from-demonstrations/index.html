備考

主な特徴
前脚1本でパラメータ化されたベジェ軌跡に追従しつつ残り3本の脚で歩行するRL低レベル制御器と、点群ベースのDP3 diffusionプランナーが軌跡パラメータを出す階層型の脚操作方策である。アームなしで脚だけを使い、ボタン押し・ドア押し・移動中のかご持ち上げなどをシミュレーションと実ロボット(Aliengo)で行った。
備考
デモは人のテレオペレーションではなく、設計した専門家軌跡パラメータをRL制御器がシミュレーションで追跡して生成; プランナーはベース速度を直接出さず、ワールド座標の目標(4 m×4 mの範囲で学習)で移動を誘導; 実ロボットの定量結果なし; コード・重み非公開。ベース: 3D Diffusion Policy: Generalizable Visuomotor Policy Learning via Simple 3D Representations (arXiv 2403.03954) — 高レベルプランナーのバックボーンとしてDP3を使用(論文に明記)
