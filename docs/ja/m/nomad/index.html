備考

主な特徴
目標画像を確率的に隠す目標マスキングで、目標指向ナビゲーションと目標なし探索を1つの拡散方策で処理する。19Mパラメータで335Mのsubgoal拡散方式より探索成功率(98% 対 77%)と衝突(0.2回 対 1.7回)を改善した。
備考
論文に行動シーケンス長・コンテキスト・解像度の記載なし → 公開nomad.yaml基準でウェイポイント8個・コンテキスト3・96×96。学習GPU・時間は非公開。ViNT方策構造に目標マスキングを結合。重みはGoogle Driveで公開。ICRA 2024。ベース: ViNT: A Foundation Model for Visual Navigation (arXiv 2306.14846) — ViNT方策構造に目標マスキング・拡散ヘッドを結合 (論文に明記)
